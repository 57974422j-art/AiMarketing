# 抖音发布页 VLM 基准图

本目录存储抖音自动化脚本中「标题/话题/位置」3个步骤的页面基准截图。

## 用途

执行动作前，VLM 会把当前截图与基准图对比，判断是否在正确的页面上。

## 文件清单

| 文件名 | 页面 | 来源 |
|--------|------|------|
| `edit_title.png` | 视频发布编辑主页（添加标题 / #话题 / 所在位置 / 发作品）| 用户上传 |
| `topic_list.png` | 话题选择列表页（热门话题 + 播放量）| 用户上传 |
| `location_popup.png` | 「所在位置」弹窗（再想想 / 所在位置 按钮）| 用户上传 |
| `location_city.png` | 城市选择搜索页（和田 / 合肥）| 用户上传 |

## 上传方法

1. 用 ADB 截图：`adb exec-out screencap -p > edit_title.png`
2. 或从手机相册导出
3. 放到此目录即可

## 分辨率要求

- 基准图分辨率应与设备一致（如 1080x2340）
- PNG 格式，保持原始分辨率不要压缩
- VLM 对比时会自动缩放适配
