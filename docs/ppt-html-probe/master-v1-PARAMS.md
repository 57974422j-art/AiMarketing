## 4. 动效令牌（`:root`，**改这里就改节奏，JS 会读**）

| 令牌 | 值 | 说明 |
|---|---|---|
| `--enter` | `.72s` | 单元素入场时长 |

| `--xover` | `.5s` | 页间转场时长（淡出+缓推，**不是硬切**） |

| `data-anim` | 效果 | 用于 |
|---|---|---|
| `rise`（默认） | 淡入 + 上移 22px | 绝大多数文字 |

| `roll` | 数字滚筒（`data-roll-steps` 指定格数） | 数据页每位数字 |

## 5. 页型契约 v1（4 页 = 一整套的最小完备）

| 页 | 必须包含（**内容下限**） |
|---|---|
| P1 封面 | 主标题（衬线大字）+ 副标 + 出品方/日期（小字） |
| P2 要点页 | 标题 + **3~5 条编号要点（每条 ≥8 字）** + 底部一句小结 |
| P3 数据页 | 标题 + **1 个大数字 + 单位 + 一句解释** + 2 个次要指标（小字） |
| P4 尾页 | 主句（可 2 行）+ CTA + 一行英文（小字） |

**硬规矩**：**不许只有一个大字**。要点页 ≥3 条且每条 ≥8 字；数据页必须有 数字+单位+解释；封面必须有 主标题+副标。

## 6. 每页时间轴（`data-at` = 相对本页起点的秒数）

页起点：P1=0 / P2=3 / P3=6 / P4=9（`--page` 改了就同步改这 4 个数与 `section` 的 `data-start`）。

| 页 | 元素（依 `data-at` 顺序） |
|---|---|
| P1 | 短横线 .10 → 眉标 .28 → 主标题 .44 → 副标 .99 → 出品方 2.05 |
| P2 | 短横线 .30 → 标题 .38 → 要点01 .58 → 02 1.08 → 03 1.58 → 04 1.76 → 小结 1.98 |
| P3 | 短横线 .30 → 标题 .38 → 大数字淡入 .46 / 滚筒 .52（`--roll`）→ 单位 .64 → 解释 1.05 → 次指标1 1.45 → 次指标2 1.75 |
| P4 | 主句1 .34 → 主句2 .62 → CTA 1.05 → 英文行 1.45 |

- **页间转场**：在页边界前后各 `--xover/2` 完成"出页淡出+上推 / 入页淡入+上推"。
- 每页底部进度线：`scaleX 0→1`，时长 = `--page`，从本页起点开始。
- **已知特性**：因为 `.page` 本身没有不透明底，两页交叉的那 ~0.4s 里画面只剩深色底 + 新页第一条元素（实测亮度 60→28→回升，**没有空屏/黑帧**）。这属于"dip 式淡入淡出"。若想要"真正交叉淡化、无 dip"：给 `.page` 加不透明同色渐变底，并把 `.glow` 移到每个 `.page` 内部（否则会被底遮住）—— **本母版未启用，留作可选调法**。

## 7. 素材规则（**踩过坑，务必遵守**）

1. 素材必须**拷进项目目录**（相对路径引用）。`file://` 绝对路径会被浏览器拦截（实测 `[media_load_failed]`）。
2. 只用 **`.mp4`（H.264）/ `.webm`（VP9）**。实测无头浏览器**不支持 `.mov`/`.avi`/`.ts`/HEVC**（`.mkv` 仅 `mayb`，不可依赖）→ 上传口收这些格式，**必须在 HTML 线入口统一转 H.264 + `+faststart`**。
3. 转码时**必须显式写死色彩标签**：`-color_range tv -colorspace bt709 -color_primaries bt709 -color_trc bt709`。实测无标签素材经 HTML 线渲染后饱和色偏 **−17%**；写上标签后偏差降到 −3%（≈消除）。
4. 封面素材用 `--photo-dim` 压暗降饱和；`mask-image` 柔化边缘使其融入深色底。

---

## 8. 字体规则（**踩过坑**）

1. **只用开源字体**（OFL）：`Noto Serif SC`（标题衬线）/ `Noto Sans SC`（正文）。**绝不内嵌 `msyh`（微软雅黑）——有授权问题**。
2. **必须内嵌**（`@font-face` + 项目内 woff2）。缺失字体时浏览器**静默回退**、不报错（实测：请求未安装的字体名与请求不存在的字体名渲染结果完全一致）。
3. **禁外部字体 CDN**（断网即静默回退，且缓存淘汰会破坏确定性）。
4. 改了文案后**必须重跑** `python subset-fonts.py`，否则新出现的字可能缺字（脚本会自动收集 `master-*.html` + `assets/master.{css,js}` 的全部字符，另加 ASCII 与常用中文标点安全集）。
5. 子集化效果：24 MB → **176 KB**（Serif）；16.9 MB → **133 KB**（Sans）。

## 9. 实测成本（本机 i7-12700F / 12 核 / RTX 级 GPU，非服务器）

| 项 | 值 |
|---|---|
| 16:9 出片（300 帧） | **`--workers 1`：引擎自报 8.7s** ／ 默认多 worker（本机取 6）：13.1s |
| 9:16 出片（300 帧） | **`--workers 1`：8.6s** ／ 默认多 worker：14.6s |
| 捕获模式 | `--workers 1` → `drawelement capture · hardware gpu` + **流式编码**；多 worker → `screenshot capture` + setup 3.0s/capture 7.2s/encode 2.3s |
| 产物大小 | 16:9 ≈ 1.9 MB / 9:16 ≈ 1.8 MB |
| 无 GPU 服务器折算 | ×1.34（截图模式已含在内，服务器上还可能更慢） |

### 9.1 **推荐渲染设置（重要）**
```bash
hyperframes render . -c master-16x9.html -o master-v1.mp4 --fps 25 --quality looks --workers 1
```
理由（实测）：`--workers 1` **同时更快且字节级可复现**——
| 对比 | MD5 | 逐帧像素 |
|---|---|---|
| 默认多 worker，渲染两次 | **不同** | PSNR 全 `inf`（像素一致） |
| **`--workers 1`，渲染两次** | **完全相同** | 一致 |
| 6 worker vs 1 worker | 不同 | PSNR 55.34 dB（肉眼不可分辨） |

根因：worker 数决定路径 —— 单 worker 走 `drawelement` + **流式编码**（顺序、可复现）；多 worker 走 `screenshot` + 分块并行编码（顺序不定）。
⇒ **要"回归测试/字节级可复现"就用 `--workers 1`；要多片并发抢吞吐时才各自调 worker，并接受"帧内容一致"这一档。**

## 11. 已知限制

1. 竖屏是"同版式复用"（同一套 CSS 变量 + `body.p` 覆盖），部分页面留白偏多（P2/P4 下半部空）—— 属可接受留白，若要更满可调 `--pad`/字阶。
2. 数据页数字滚筒是**按位滚筒**（odometer），不是"从 0 连续长到 82"的数值插值；纯 transform、逐帧可 seek、无 JS 依赖。
3. 本母版**未含**旁白/BGM/字幕（按现有链路在拼接后统一加）。
4. **默认多 worker 会走 `screenshot` 捕获 + 分块并行编码** → 比单 worker 慢（约 1.5×），且两次渲染只到"帧内容一致"（MD5 不同）。要"又快又字节可复现"就用 `--workers 1`（见 §9.1）。
5. **`density` 枚举只改版心/节奏，字阶不随密度变**（如实声明，避免"契约比实际能力强"）：
   - 现状：`airy` → `--pad:96px/--gap:24px`；`normal` → 母版默认；`dense` → `--pad:72px/--gap:16px`。
   - **不接字阶的原因**：改字阶要覆盖「3~5 条要点 × 三种密度」的全部组合并逐一目视防溢出，属"需要渲图验证"的改动；在拿到老板的观感判词前做，有大概率白做（team-lead 2026-10-02 定：先不做）。
   - 影响面：`--pad` 同时被 `.progress`、`.issuer`、各页标题起点使用，所以改密度会让**整页版心**一起变，是"整体松紧"而不是"字号大小"。
