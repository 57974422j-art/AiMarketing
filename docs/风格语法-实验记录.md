# 风格「语法」实验记录（2026-10-10 · 边做边记）

> 起因（用户一眼看穿）：上一轮 4 个风格**只有颜色变了，样式一模一样**。
> 诊断：我的规格 v0 只覆盖了 **L0 皮肤（tokens）**，而 **L1 构图 / L2 动效 / L3 文本形态** 被写死在生成器里 ⇒ 必然"换色不换式"。
> 本实验要证明/证伪：**把 L0 固定住、只换 L1~L3**，三条片能不能看不出是同一套？
> 纪律：**只做实验，不动产品代码**；产物在 `temp/_travfilm/`，本文件同步记录。

## 二、只换的三层语法（规格 v1 字段）

| 字段 | A 满幅电影感 | B 拼贴手作 | C 极简纸面 |
|---|---|---|---|
| `layout.system` | axis（中轴/底部对齐） | free（自由错位 + 旋转） | grid（固定网格 + 大留白） |
| `image.place` | **fullbleed**（铺满裁切） | **mat-tape**（白边相纸 + 胶带 + 旋转） | **mat**（相纸，居中缩小） |
| `image.perPage` | 1（另有双联/四联页） | 3（密） | 1（疏，另有 3/4 联页） |
| `whitespace` | 0.15 | 0.08 | **0.55** |
| `pacing.avg` | 4.8s，硬切 | 8.7s 页内快弹 | 6.7s，极慢 |
| `transitions` | **cut**（0.06s 交叉） | pop（弹入 + 过冲） | fade（1.6s 长淡入） |
| `order` | 图先→字后压图 | 图与贴纸同现 | 图先→停 1.2s→字 |
| `title.form` | 横排大字压图 + 细线 | **贴纸块 + 旋转** | 竖排小字 + 极细线 |
| `ornament` | rule + 页码 | tape + 荧光块 | hairline 仅此 |

## 三、预期（先写下来，等验证）

1. 三条**看不出是同一套**（差异来自语法，不来自颜色）⇒ 说明"风格 = 语法"成立。
2. A 会像预告片、B 像小红书拼贴、C 像画册/明信片。
3. **已知取舍（要用户拍板）**：
   - **A 的"满幅"必然裁切** ⇒ 与上一轮"图片必须完整"的要求**冲突**（这是"满幅电影感"的代价）。
   - B 密度高 ⇒ 单张图看清的时间短。
   - C 节奏慢 ⇒ 信息量少，但质感最稳。

### 4.2 执行记录（2026-10-10，按时间追加）

**① 生成器写完**：`temp/_travfilm/_gen2.mjs`（语法参数化：`motion.img` = push|pop|fade、`motion.ease` = out|back|inout、`motion.type` = overlay|sticker|vertical、`motion.cross` 转场时长；构图按 mode 分支）。

**② 过闸门（首次）**
| 模式 | 字表闸门 | 引擎 check |
|---|---|---|
| cinematic | ❌ **1 个表外字「檐」** | ✓ Check passed（`6/6 text checks pass WCAG AA`） |
| collage | ✓ 133 字符全在表内 | ✓ Check passed（`19/19 WCAG AA`） |
| quiet | ✓ 75 字符全在表内 | ✓ Check passed（`5/5 WCAG AA`） |
→ 修：A 版标题「檐」→「廊」（**同一个坑我踩了两次**，说明"字表白名单"这条闸门必须自动化，不能靠记性）。

**③ 渲染**（25fps · 720×1280 · 均 45~60s 内）
| 模式 | 时长 | 体积 | 渲染耗时 |
|---|---|---|---|
| cinematic | 52.6s | 24.9MB | 56.1s |
| collage | 52.2s | 6.6MB | 1m21s |
| quiet | 53.6s | 4.8MB | 18.2s |

**④ 抽帧对比**：`temp/_peek/gr/gcmp_0.jpg`（单图页）· `temp/_peek/gr/gcmp_1.jpg`（多图页，左→右：满幅/拼贴/极简）

**⑤ 我自己的观感（诚实）**
- **A 满幅**：像预告片 —— 白字压图 + 暗场渐变 + 细线，最"有气势"；代价是**裁切**（与"图片完整"冲突）。
- **B 拼贴**：像手账/小红书 —— 贴纸标题 + 相纸旋转 + 胶带 + 标签，信息密度最高；单张图看清时间短。
- **C 极简**：像画册/明信片 —— 小图 + 一行衬线字 + 极大留白，质感最稳；缺点是**信息量少、手机上图偏小**（288px / 720）。

**⑥ 关键结论**
1. **样式差异确实来自语法（L1/L2/L3），不是颜色** —— 三条 tokens 完全相同（同纸同墨同点缀色），肉眼一看就是三套。
2. **闸门可复用**：同一套 `check-page-fonts.mjs` + 引擎 check 对三种语法都有效；**拼贴的"故意叠压"没有被拦**（说明引擎只判文字碰撞/对比度/溢出，不拦照片叠压）⇒ 构图自由度有空间。
3. **闸门对"我"有效**：抓出表外字「檐」（两次）；A 版压图白字在暗场渐变下 `6/6` 通过，证明"满幅压字"可以做到既好看又达标。

**⑦ 待决策（要用户拍板）**
1. **"图片完整" vs "满幅电影感"**：二者天然冲突（满幅必然裁切）。是否允许**按风格声明**——"此风格固定裁切" / "此风格保证完整"？
2. **密度**：B 类拼贴单图停留短，是否设"单图最短可见时长"（例如 ≥2.5s）？
3. **C 类图偏小**：是否给"最小图宽"下限（例如 ≥ 320px）以防"看着像空页"？
4. **自由度的边界**：允许 AI 发明**新页型**吗（本实验的三种语法都不是库里那 6 种结构）？我的建议：**允许生成，但入库需你点头**（候选 → 正式）。

**⑧ 规格 v1 应落的字段（从这次实验反推）**
```
layout:   { system: axis|free|grid, whitespace: 0.08~0.55, align: … }
image:    { place: fullbleed|mat|mat-tape|overlay, perPage: 1~4, complete: true|false }   ← complete 必须显式声明
pacing:   { avgSec: 2~9, fast:[…], slow:[…] }
motion:   { img: push|pop|fade, ease: out|back|inout, type: overlay|sticker|vertical, cross: 0.06~0.8, push: 0.08 }
text:     { titleForm: overlay|sticker|vertical, titleSize, tracking, ornament: rule|tape|hairline|none }
gates:    { minImageWidth: 320, minShotSec: 2.5, charset: true, wcagAA: true }            ← 把"取舍"写成可校验字段
```

**⑨ 逐页自查（每片抽 9 帧：`temp/_peek/gr/audit_*.jpg`）—— 我找到的问题（按严重度）**

| # | 问题 | 证据 | 影响风格 | 修法（候选） |
|---|---|---|---|---|
| 1 | **换页像"闪一下白"** | A 满幅页的入场是"整页 opacity 0→1"，底下是**浅纸色** ⇒ 深图之间插了一帧亮底；t≈33s 那帧发白 | A（满幅） | 满幅页**不改 opacity**，改成"黑色幕布"淡出/或 clip-path 揭示 |
| 2 | **入场瞬间出现"空白相纸"** | B 的入场把**整块 `.ph`**（含白边）一起淡入 ⇒ 先看到一张空白白纸再出图；t≈9s 可见 | B（拼贴） | 白边常驻，只动 `<img>` 的 opacity / 或白相纸做 wipe 揭示 |
| 3 | **节奏完全均匀**（无快慢） | A 每页 4.6~5.0s、B 每页 8.7s、C 每页 6.7s，**全程一个速度** | 三条 | 规格加 `pacing.fast/slow`：至少一处快切（0.9~1.5s）+ 一处长留（8s+） |
| 4 | **裁切过狠** | A 三竖条页是 240×1280（原图 3:4 ⇒ 裁掉约 78% 宽度）、四宫格 360×640 也重裁 | A | 加约束"裁切后长宽比 ≤ 原比例 ×1.6"，或竖条改 contain+同色底 |
| 5 | **长叠化吃时间** | C 用 0.8s 叠化 + 6.7s 页长 ⇒ 每页约 12% 时间在半透明（观感"发灰/发空"）；t≈33s 几乎看不到内容 | C | 叠化缩到 0.35~0.5s，或页长加到 8s |
| 6 | **图偏小 / 装饰无效** | C 单图 288×384（仅占宽 40%），1px hairline（50% 灰）几乎看不见 | C | 单图最小宽 ≥320px；hairline 加粗到 2px 或用点缀色 |
| 7 | **小字在手机上看不清** | B 的照片标签 12px 且随图旋转；A 的 eyebrow 15px / 字距 7 | A、B | 最小字号 ≥14px（标签 ≥15px）、旋转文本改用"贴纸"形式而非随图转 |
| 8 | **文案与素材贴合度低** | A 的「四时」「廊」是我人肉拍的抽象标题，与四张具体素材关系弱 | 三条 | 标题/句子应由 AI **从每张读图描述**生成（这次实验里没做，AI 参与度不足） |
| 9 | **无音频** | 三条都无声（项目无可用 BGM 素材） | 三条 | 配 TTS 旁白 或 用户提供音乐后混音 |
| 10 | **尾页处理弱** | A 尾页无图、只有竖排小字（与全片满幅反差过大）；「下次再来」16px 太淡 | A | 尾页用最后一张图压暗 + 落款（与正片同语法） |
