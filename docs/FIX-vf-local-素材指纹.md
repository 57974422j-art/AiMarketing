## 一、要修的问题（用户实测）

用「**图片成片**」这条线，个人仓库里的素材**全是火锅照片**，但产出视频的**文字内容却是"以前关于项目的语言"**，与素材毫无关系。

**用户强调**：「以前一直是好的」。查证结论：**不是"以前好、现在坏"，而是这道防护从来没存在过** —— 见下。

## 三、目标

给「图片成片」加一道保护：**素材指纹变了 ⇒ 旧内容自动作废 + 如实告知用户**；**用户设置不受影响**。

## 四、改哪里

**只改一个文件**：`src/app/api/agent/chat/route.ts`

| # | 落点 | 做什么 |
|---|---|---|
| 1 | 新增纯函数 `matSigOf(items)` | 对素材清单算签名。**复用已有口径**：`src/lib/agent/vf/material-pool.ts` 的 `vlCacheKey`（`仓库key@字节大小`）⇒ 与"看图缓存命中"口径**零漂移**；**建议再拼 `name`**（防"key 与 size 恰好都相同"的漏判） |
| 2 | 写入签名（两处） | 起草处（grep `vd.imgs =`）旁加 `vd.matSig = matSigOf(...)`；重排函数 `_replanFromDraft` 内（grep `_replanFromDraft`）同步刷新 `draft.matSig` |
| 3 | **比对点** | 在块入口、`vd` 刚 load/清完、**尚未分派**处插入判断。⚠️ **必须放在以下三个判断之后**：`VF_EDIT`「只重渲」、`VF_FORM` 孤儿认领、`running` 过期自清 —— 否则会把它们误清 |
| 4 | 触发条件（省成本） | 仅在"可能重来"的消息上算指纹：`vfIntent \|\| _vfIsForm \|\| vd.step === 'script'`（后者需 `await listRepoMaterials(...)`，与主取材同参） |
| 5 | 不一致时**清什么** | 清**内容**：`topic / script / shots / cover / subLen / imgs / brief / briefOverride / matSig`；`step` 退回 `'source'`（或 `'form'`）。**保留设置**：皮肤 / 音色 / 画幅 / 时长 / i2v / 风格 / 大字等 |
| 6 | 告知话术 | 照 `vf-htmlfilm.ts` 的形制：「**素材变了，旧文案/旧分镜已作废**，请按当前素材重排」 |

**不要**：用 `clearVfDraft` 整条清（会把用户设置一起清掉）。

## 五、硬边界（不守就会弄坏别的线）

1. ⚠️ **必须限定 `line === 'local'`**（只对图片成片生效）—— 这块状态机与 **`vf_pptimg`（PPT+图视）共用**；若不加限定，会弄坏 PPT+图视的"**换线作废**"（那是 2026-10-07 刚修过的点，**别改回去**）。
2. **别碰那三条旁路**：`VF_EDIT` 只重渲 / `VF_FORM` 孤儿表单认领 / `running` 过期自清。新判据放它们**之后**。
3. **只清 `vf_draft_base` 这个 tag 对应草稿的"内容字段"**，别波及 `vf_draft_ai` / `vf_draft_mix` / `vf_draft_video` / `vf_draft_htmlfilm`。
4. **别改素材来源口径**（那是另一个改造包 B 的事，见 `docs/FIX-素材口径漏网.md`）。
5. **别动** `src/lib/agent/video-material.ts` / `material-pool.ts` 的既有行为（它们是 7 条线共用的咽喉）—— 除了**新增** `matSigOf`（纯函数、只增不改）。

## 七、坑（已知，别重踩）

- **草稿是 DB 持久化的**（跨会话、跨天都在）⇒ 测试时先确认自己处在"上一条草稿还活着"的状态，否则复现不了；
- **指纹别读 `.vl_cache.json` 文件**（那只含"已识别过"的图）⇒ 应该用**同一套键公式**从素材清单**现算**；
- **上传素材路径要保住**：用户上传的原片**不打 `gen_` 前缀**，回取时是"按名单精确匹配 + 最近上传回退"（grep `上传名单在仓库里都没找到`）⇒ 你的改动**不要给这条路新增过滤条件**，否则会出现"上传的文件找不到"的静默回退；
- **只改一个文件**：如果发现必须改别处，**先回来问**（本对话是"规划/核对"窗口），别自己扩散。
