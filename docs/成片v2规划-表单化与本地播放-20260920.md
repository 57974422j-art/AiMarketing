## 二、★ 交互改造：把 4 张卡合成「一张表单」（你提的，优先级最高）

### 现状（4 轮才开工）
```
点「帮我做一个视频」
 → 卡1：素材来源（素材合成/混合/全AI/上传）  ← 点一次
 → 又返回卡1（多了画幅）                      ← 点一次
 → 又返回卡1（多了时长）                      ← 点一次
 → 点「素材合成」                             ← 再点一次
 → 才排分镜
```
**毛病**：每点一次都要"发消息 → 服务器 → 回卡"，既慢又像"打一枪换一个地方"。

### 目标（1 轮开工）
```
点「帮我做一个视频」
 → 弹出【成片设置表单】（一张卡里全部选项，都有默认值）
     画面来源  ( ) 素材合成  ( ) 素材+AI 混合(开发中)  ( ) 全部 AI(开发中)
     画幅      ( ) 竖屏 9:16   ( ) 横屏 16:9   (•) 自动（按素材判断）
     时长      (•) 30秒  ( ) 60秒  ( ) 90秒  ( ) 180秒  [___] 自定义
     音色      (•) 龙小淳    ( ) 龙嫗    ( ) 火山     [ 我的克隆音色… ]
     主题      [__________]（可留空，AI 自己决定；也可直接贴一段文案）
              [ 🚀 开始出片 ]
 → 点【开始出片】= 一次性提交 → 服务器一次算完（取素材 + 写字 + 排镜）→ 出「确认卡」
```
**关键设计**：
1. **表单有默认值** → 用户**什么都不改也能直接点"开始"**（真正的"一键出发"）
2. **一次提交只发一条消息**：`VF_FORM:{aspect,dur,source,voice,topic}`（结构化，不用人话）
3. **保留"直接说话"**：用户直接打「帮我做一个视频：咖啡店开业」→ 跳过表单，用默认值开工（不强制填表）
4. **音色并入表单** → 出片前不用再单独点音色（少一轮）
5. **表单提交后** 才去取素材/写字/排镜 → 出「文案 + 分镜」确认卡（那时候才需要用户"确认出片"）

**改动量**：
- 前端：`VF_JSON.step='form'` 渲染成表单（单选/输入）→ 提交发 `VF_FORM:...`
- 后端：解析 `VF_FORM` → 填草稿 → **一次走完取料+起草**（不再逐项等）
- 兼容：老的分步按钮**保留**（万一用户想一项项调）

## 三、★ 播放改造：客户端播本地、网页播 OSS（你提的）

### 现状
```
<video src="/api/storage/file?name=xx.mp4"> → 服务器 → OSS → 浏览器
                                                     ↑ 受网络/带宽影响，且要过服务器
```

### 目标（双路）
| 环境 | 播放源 | 说明 |
|---|---|---|
| **Electron 客户端** | **本地库文件**（`安装目录\storage\xxx.mp4`，`file://` 或自定义协议） | **零网络**，绝不卡；而且**本来就要镜像到本地**（你们既有规则） |
| **网页端**（浏览器） | 服务器 `/api/storage/file`（**302 → OSS**，Range 生效） | 只能走网络，但 Range 保证边下边播 |

**要点**：
- 成片完成后，客户端已经会 `storage:mirror` 把它拉到本地（**现有机制**）→ 播放时**优先用本地路径**，没有才回落网络
- **需要改 `electron/`** → 按你们的规矩，**客户端改动要重新打包发版**（这次可以先只做网页端，客户端留到下个版本）

## 四、长视频（问题 1）要查的

**已知**：24 镜、文案 800 字，但成片 42 秒 → **配音只念了 ~190 字**。

**三个可能**（要按顺序查）：
1. **`tts.py` 逐句合成时有失败被跳过** → 丢句 → 总时长变短（最可能）
2. **TTS 单次文本上限**（百炼 CosyVoice 对长文本有限制）→ 超长句被截断
3. **`voice.m4a` 合并时只合并了部分** → 后面的句子没进去

**查法**（不猜，看数据）：
```bash
# ① 任务日志里配音阶段输出（tts.py 会打印每句）
cat $(ls -t /root/AiMarketing/storage/1/video-factory/vf*.json | head -1) | head -60
# ② 数一数实际生成了几个句子音频（对得上 24 镜吗）
ls /root/AiMarketing/storage/1/video-factory/work_*/tts/*.mp3 | wc -l
```
