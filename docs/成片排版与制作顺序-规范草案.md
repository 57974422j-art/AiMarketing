> 起因（用户原话）：
> 「只谈排版。满屏问题不大，**能有转场效果最好**。但你看那个 `collage.mp4`：**每帧 3 个图去填充、前片一律**。」
> 「总结记录，一会怎么调整、怎么**灌输给我们的 AGENT 不犯错误**，**不用固定格式**，怎么能做到。不要再实验了。」

---

## 零、一句话结论

> **不固定格式，只固定"判据"**：AI 自由设计每一页的版式，但必须过一组**可自动校验的判据**（页间要有变化、图数要有变化、节奏要有起伏、转场要给、字数/字号有底线）；不过就**打回重写**，而不是我们给它套模板。

## 一、病灶（用户点名的 + 我自查的）

| # | 病灶 | 现场 | 根因 |
|---|---|---|---|
| 1 | **每页一个模子**：`collage` 每页固定"3 张图 + 同一个位置 + 同一个动效" | `collage.mp4` 全片 6 页都是 3 格同构 | 生成器把每页 `kind` 与几何写死 ⇒ 缺 `variation`（同构/递进/对比）字段 |
| 2 | **"填充感"**：图数不变（永远 3 张） | 同上 | 缺"图数变化"要求（1/2/3/4 混排） |
| 3 | **节奏一律** | 三条片每页时长都是常数 | 缺 `pacing.fast/slow` |
| 4 | **没有转场意识** | 只有整页淡入/硬切，没有"擦/推/遮罩" | 缺 `transitions` 集合与"为什么用这个转场" |
| 5 | 次要：裁切过狠、小字过小、长叠化吃时间、无音频 | 见 `docs/风格语法-实验记录.md` §⑨ | 缺 `image.minCropAspect` / `minFontSize` / `enter` 方式 |

## 二、排版原则（**灌输给 AGENT 的判据清单**，不是模板）

> 口径：**原则 + 可校验判据**；AI 怎么排由它自己决定，只要求"过判据"。

### A. 页间必须有变化（治"前片一律"）
- **A1 版式签名**：每页算一个 `signature = 图数 + 对齐方式 + 图呈现方式 + 标题形态 + 留白档`。
- **A2 判据**：① 相邻两页 signature **不得相同**；② 全片 ≥3 种 signature；③ **同一 signature 连续不超过 2 页**。

### B. 图数要变（治"每帧 3 张填充"）
- **B1 判据**：全片至少出现 **2 种不同图数**（推荐 1 / 2 / 3 / 4 混排）；连续 3 页同图数 ⇒ 打回。
- **B2 一页最多 4 张**（超过就变成"贴图墙"）。

### C. 节奏要有起伏（治"匀速"）
- **C1 判据**：`max(页长) / min(页长) ≥ 2`；且至少 **1 页 ≤ 2.5s**（快）、至少 **1 页 ≥ 6s**（长留）。
- **C2**：快页用于"信息密集/同类素材"，长留页用于"单张好图 + 一句话"。

### D. 转场要给，而且要有理由
- **D1 转场集合**（至少给 2 种）：`cut 硬切` / `wipe 擦` / `dissolve 叠化` / `push 推` / `mask 遮罩揭示` / `match-cut 同形接`。
- **D2 用理由**：同场景推进=叠化或推；**换场景/换主体=硬切**；"同类多图→单张焦点"=遮罩揭示。
- **D3 判据**：全片 ≥2 种转场；相邻同转场 ≤2 次；转场时长 **0.25~0.6s**（叠化不超过 0.6s，避免"半透明发灰"）。

### E. 满屏与"完整图"的配额（用户：满屏问题不大）
- **E1**：满屏（full-bleed）**允许**，但**裁切后长宽比 ≤ 原图 ×1.6**（避免把主体切掉）。
- **E2**：全片**完整呈现的图 ≥ 6~7 张**（用户定的底线）——满屏与完整可以混用，但配额要满足。

### F. 文字样式（层级，而不是模板）
- **F1 三档层级**：`主标题`（画面最重）、`副题/一句`、`标注/标签`。
- **F2 判据**：最小字号 ≥14px、标签 ≥15px；**旋转的文字不可读**（标题/标签不随图旋转）；压图文字必须**自带底衬或暗场/亮场**（保证 WCAG ≥4.5:1）。
- **F3 字数上限**（防溢出）：标题 ≤6 字、副题 ≤20 字、每页在屏字 ≤60 字。
- **F4 字表**：必须在引擎字体子集内（已有闸门自动拦，AI 不许写生僻字）。

### G. 留白与"动作高光"
- **G1 留白率**：每页留白在 **0.08~0.55** 之间；连续 3 页留白档相同 ⇒ 打回。
- **G2**：每页允许 **1~2 个"动作高光"**（一次推近 / 一次擦入 / 一次数字滚动）；**不要每页用同一套动作**。

### H. 禁止项（任一出现即打回）
1. 连续两页同 signature；2. 全片只有一种图数；3. 全片一种转场或没有转场；
4. 匀速（快慢比 <2）；5. 小字 <14px 或标题随图旋转；6. 压图无底衬导致对比不足；
7. 满屏裁切超过 1.6× 仍要硬裁；8. 完整图少于 6 张。

## 三、制作顺序（**本草案的重点讨论项**）

### 3.1 文案其实是**两层**，不能混着谈

| 层 | 属于 | 决定什么 | 什么时候要 |
|---|---|---|---|
| **画面字**（在屏文案：标题/副题/标签） | **排版/设计** | 字号、断行、位置、留白 | **排版阶段就要**（否则没法排版） |
| **口播字**（配音文案） | **音频** | 时长、字幕 | **配音阶段要** |

⇒ 用户问的"成片后再加文案"——**只能后加"画面字"（重出一遍），绝不能后加"口播字"**：因为口播决定时长与字幕，成片后再贴音轨 ⇒ 与画面对不上、字幕要重排 ⇒ 等于重出片。

### 3.2 推荐顺序（7 步）

```
① 分镜骨架   ：页数 / 每页图数与哪几张 / 时长意图 / 节奏（快慢各在哪） / 转场意图
              —— **不含具体词**，但含"每条字数上限"
② 排版+动效  ：HTML/CSS + 时间轴（版式、入场、转场、动作高光）
              —— 先用**占位文字**（长度真实）渲一遍"占位版"，确认版式不空、不溢出
③ 画面字     ：AI 读每张素材写标题/副题/标签（满足 ② 的字数上限）
④ 口播字     ：单独写（≤18 字/镜、口语、**不与画面字重复**）
⑤ TTS → 实测时长回填 → 字幕（时长由语音定，画面随之伸缩）
⑥ 混音 + 烧字幕 → 成片
⑦ 审核微调   ：只改字不动时长；**若要改时长 ⇒ 回 ⑤ 重出**
```

### 3.3 为什么必须"先排版、后文案"（而不是先写文案再排版）

| 顺序 | 好处 | 代价 |
|---|---|---|
| **先文案 → 再排版**（老做法） | 文案一次到位 | 文案一掉（如今天）⇒ 分镜空 ⇒ **没字没声、每镜 2.2s**；且文案长度不受版式约束 ⇒ 溢出/断行难看 |
| **先排版（占位）→ 再填文案**（推荐） | 版式先立住；**占位文字保证时长与画面不塌**；文案只需满足"字数上限" | 多一次渲染（占位版）——便宜，可复用 |

### 3.4 「前面只让出 HTML 的文案」= 对的，但要写清"两种字"的分工

- 排版阶段只产出**画面字**（且先给占位）；
- 口播字**独立一步**产出（可复用画面字的素材描述，但**不照抄**）。

## 四、怎么"灌输给 AGENT 而不犯错"（不用固定格式）

1. **给 AI 的是一页纸口径 + 判据**，不给模板：
   ```
   你输出 pages[]：每页 { images[], layoutIntent, imageMode, perPageStyle,
                          titleShape, transition, durSec, onScreenText 上限, motion }
   硬判据（不过就重写）：A1-A2 / B1-B2 / C1 / D1-D3 / E1-E2 / F1-F4 / G1-G2 / H1-H8
   ```
2. **机器判（自动打回）**：A2、B1、C1、D3、E1、F2(字号/对比)、F3、F4、G1 —— 这些都是**可计算**的，直接写进校验器，**不满足就打回重写（最多 2 次）**。
3. **人判（你看片）**：转场"有没有理由"、动作高光"好不好看"、配色味道 —— 这些给你一句"采纳/淘汰 + 原因"，写回参考语料。
4. **反例清单**（喂给 AI + 写进校验器）：
   - ❌ 每页 3 张同位置（本次 collage）
   - ❌ 全片一种转场/没有转场
   - ❌ 匀速
   - ❌ 小字 <14px、标题随图旋转
   - ❌ 压图没底衬
   - ❌ 完整图 <6 张

## 五、本轮落地（2026-10-10 · 用 17 张火锅实拍实做了一条，判据已进引擎）

### 5.1 新增「完整大图」版式（治"每帧 3 个图填充 / 前片一律"）
- `tools/film-to-page.mjs`：`FILM_STRUCTS` 增 `plate-top` / `plate-bottom`（两种构图：**大标题在上** / **文案在下**）。
- **边缘处理的口径**（用户说"这是你的事"）：4:3 实拍放进 9:16 竖屏必然四周留空 ——
  **不用黑边/白边**，而是「同图放大模糊铺满图框 + 8px 白边 + 极淡投影」（像一张冲洗出来的照片压在纸上）。
- 图用 `object-fit:contain` ⇒ **整张不裁**；**图永不缩放**（一缩放就吃掉边缘、就不是"完整"了），
  动效只走"整块照片轻微落定 + 极慢上浮"。
- 图占画幅 **696/720 = 97% 宽**（4:3 ⇒ 522 高）。

### 5.2 转场（治"没有转场"）
- 运行时 `tools/runtime/film.js` 支持每段 `trans`：`fade` 叠化 / `wipe` 擦除 / `push` 推移 / `cut` 硬切。
- **真凶（逐帧查出来的）**：渲染器按每段 `data-start/data-duration` **掐窗口** —— 上一段到点被整段掐掉，
  于是"淡出没走完、下一段没铺上来"⇒ 画面空 0.5 秒，**任何转场都活不过这一掐**。
  ⇒ 修法：`data-duration` **统一多留 0.7s**（转场重叠区），出入场重叠后才成为真转场。
- 出场由**下一段的类型**决定：`cut` 到点即隐、`fade` 交叉淡出、`wipe/push` 不动（等被盖住）。

### 5.3 完整大图配额**进闸门**（治"AGENT 下次又排错"）
- `tools/arrange.mjs`（AGENT 骨架的唯一来源）：`★VF_ARRANGE_V3` 按
  `p = round((n-1) × 0.35)` 排完整大图 ⇒ **每 10 张 3~4 张**，并**交错**（多图页后跟 1~2 张完整大图，
  相邻两页页型必然不同）；零头 1~2 张走 `fullbleed`（满屏）。
- `tools/render-film.mjs`：出片前**数一遍**（`stage=plate`）。片子里声明 `requirePlate:true` ⇒ **不达标拒渲**；
  老片子没声明 ⇒ 只打印不拦（不把历史产物判死）。
  - 正例：`food-plate-v1` → `完整大图: 6/17 = 每 10 张 3.5 张` ✓
  - 反例：10 张全满屏 + 声明硬口径 → `✗ stage=plate`、exit 1 ✓（闸门不是摆设）
- AGENT 提示词（`src/lib/agent/vf/vf-htmlfilm.ts`）：① `guide` 里补上两种完整大图版式的 slots；
  ② 硬规矩加第 7 条「排版纪律」：完整大图页**不许改结构/挪素材**，文案只写"这一张里真有的东西"。
