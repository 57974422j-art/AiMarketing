# 三层定位器架构

关键词：`抖音自动化` `UI定位` `容错架构` `云端配置`

---

## 痛点

抖音每次更新，旧版定位代码大概率失效，需手动追踪界面变化修改代码。本文档定义一套高容错三层定位方案，**核心思想：主力方案快速可靠 → 备用方案模糊容错 → 兜底方案云端热更新，三层逐级降级，不改代码也能应对改版。**

---

## 三层架构

```
┌──────────────────────────────────────────────────────────────┐
│  Layer 1: 导航栏锚点反推（主力）                              │
│  ┌──────────────────────────────────────────────────────────┐│
│  │ "首页" + "我" → 确定 NavBar 边界                         ││
│  │ → 5 等分 → 第 3 个 Tab = "+" 坐标                        ││
│  │ → 点击后验证出现"相册"（短轮询 3 次）                     ││
│  │ 补丁3: 锚点中心偏上 10px 避开小白条                        ││
│  │ 耗时: ~200ms, 1次 dumpXml                                ││
│  │ 适用: "+" / 首页 / 消息 / 我 (导航栏上全部按钮)            ││
│  └──────────────────────────────────────────────────────────┘│
│                            ↓ 失败                             │
│  Layer 2: Fuzzy XML + 多策略（备用）                          │
│  ┌──────────────────────────────────────────────────────────┐│
│  │ 文字模糊匹配 + 位置权重 + clickable 优先                   ││
│  │ 复用 Layer 1 的 dumpXml（不额外开销）                      ││
│  │ 补丁1: 红点干扰 → 向上找 clickable 祖先                   ││
│  │ 补丁2: 同名干扰 → Y≥80% + 高度 30-200px 过滤              ││
│  │ 耗时: ~200ms                                              ││
│  │ 适用: "下一步" / "发作品" / "发布" 等文字按钮               ││
│  └──────────────────────────────────────────────────────────┘│
│                            ↓ 失败                             │
│  Layer 3: 云端坐标 + 本地缓存（兜底）                         │
│  ┌──────────────────────────────────────────────────────────┐│
│  │ fetchCloudCoordinate('douyin_plus_button')                ││
│  │ 远端 JSON（分辨率x按钮名 → 百分比坐标）                     ││
│  │ 本地缓存 /tmp/douyin_coords_cache.json                     ││
│  │ 抖音大改版时远程修复，不改代码                              ││
│  │ 仅触发一次网络请求，结果缓存到本地                           ││
│  │ 维护方式选 A（手动维护 JSON）                              ││
│  └──────────────────────────────────────────────────────────┘│
└──────────────────────────────────────────────────────────────┘
```

## 三层映射到 publishVideo 流程

```
publishVideo(apiPort, options)
│
├─ 第一步：点击加号
│   ├─ Layer 1: findPlusByAnchorRobust()       // 锚点反推
│   │   └─ 失败 → Layer 2: fuzzyFind('+','发布','添加')
│   │       └─ 失败 → Layer 3: cloudCoord.get('plus_button')
│
├─ 第二步：点击"相册"
│   ├─ Layer 2: fuzzyFind('相册','视频')
│   │   └─ 失败 → Layer 3: cloudCoord.get('album_tab')
│
├─ 第三步：选视频 + 两次"下一步"
│   ├─ Layer 2: fuzzyFind('下一步')
│   │   └─ 失败 → Layer 3: cloudCoord.get('next_step')
│
├─ 第四步：编辑封面 / 标题 / 话题
│   ├─ Layer 2: fuzzyFind('编辑封面')
│   ├─ Layer 2: fuzzyFind('添加标题')
│   └─ Layer 2: fuzzyFind('话题')
│       └─ 任何失败 → Layer 3: 对应 cloudCoord
│
└─ 第五步：点击"发作品"
    ├─ Layer 2: fuzzyFind('发作品','发布')
    │   └─ 失败 → Layer 3: cloudCoord.get('publish_confirm')
```

## 数据结构（云端 JSON）

```typescript
interface CloudCoordCache {
  version: string;               // 版本号
  updateTime: number;            // 更新时间戳
  buttons: {
    [key: string /* "1080|plus_button" */]: {
      x: number;                 // 绝对坐标 x
      y: number;                 // 绝对坐标 y
      xPercent: number;          // 相对比例 x
      yPercent: number;          // 相对比例 y
      description: string;       // 按钮描述
      lastVerified: number;      // 最后验证时间
    }
  }
}
```

Key 格式: `"{宽度}|{按钮名}"`，如 `"1080|plus_button"`
