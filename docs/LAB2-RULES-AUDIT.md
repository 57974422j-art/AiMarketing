## 二、「横杠」和「字重叠」的规则在哪

### 横杠（扫描线盖图）

**规则写在**：`TEXTURE` 层第 ③ 项

```
③ 扫描线：repeating-linear-gradient(180deg, rgba(0,0,0,.12) 0 1px, transparent 1px 3px)
```

**漏了什么**：
- ❌ 没写 `opacity` 上限（它给了 **.5**，我们示例是 .12）
- ❌ 没写「不许盖在图片上」
- ❌ 没写「只压纯色背景区」

⇒ **实测后果**：`.scan { z-index:59; opacity:.5 }` 盖住全部照片 ⇒ 每张图有细横杠。

### 字重叠

**规则写在**：`HARD_RULES` 的「排版」组

```
❌ 文字安全区：大字覆盖的区域不许放任何其他文字
```

**漏了什么**：
- ❌ 没说"绝对定位必须用 `top + 高度 + 间距` 算下一块的位置"
- ❌ 没说"相邻文字块的最小间距"（它 `.title` 到 995px，`.desc` 从 948px 开始，重叠 47px）

⇒ **规则是"结果禁令"，没给"计算方法"** ⇒ 它不知道怎么保证。

## 三、冲突清单（这就是「跑错」的原因）

### 🔴 冲突 1：`TEXTURE` 要求"扫描线"，但没限制"不许盖图"

```
TEXTURE：至少用一样"脏"，扫描线是选项之一
HARD_RULES：❌ 禁在整张图上盖半透明深色层来"突出文字"
        ↓
扫描线本质就是"盖一层半透明" ⇒ 两条打架
        ↓
它的解法：扫描线 z-index 59，覆盖全屏 ⇒ 图被划伤
```

### 🔴 冲突 2：`TEXTURE` 要"干净不能像模板" vs `内容类型·情绪空镜` 要"极简不加装饰"

```
DIRECTOR：干净得像模板 = 不合格 ⇒ 必须加质感
mood 类型：❌ 不用装饰 / 不加染色
        ↓
⇒ 选了 mood 它不知道往哪倒
```

### 🟠 冲突 3：`HARD_RULES` 25 条 vs 「禁止偷懒 7 条」

```
两处都在讲"该用什么"，有重叠：
  · HARD_RULES「工具」组：SVG 用于描边字
  · 禁止偷懒 ①：必须用 SVG
        ↓
⇒ 重复了一遍，占了 prompt 空间，但没增加信息
```

### 🟠 冲突 4：`装饰清单` 藏在两处

```
1. HARD_RULES 的「三道闸」第③条：每段至少 3 类装饰
2. 独立一段【装饰清单 · 每段至少挑 3 类】
        ↓
⇒ 同一条规则说了两遍
```
