# AGENT 页 ·「智能获客」使用说明书

> 面向：完全没用过的新用户（不需要懂技术）。
> 说明日期：2026-10-12。**每条结论都有代码依据**（见文末「核实清单」）；代码里读不到的，一律写「未验证」，不猜。

---

## 一、这是什么（一句话）

「智能获客」是 **AGENT 页**里的一个功能按钮，点它/对它说「智能获客」会出现一张**设置表格**——
你在这里先告诉它：**要去哪些平台、用哪些话术、找什么样的人、每天最多发多少、线索从哪来**，
然后**保存**或**看一眼预演清单**。

> ⚠️ 最重要的一句：**它现在还不会真的去发评论/私信。** 本轮只做「配置 + 预演」。
> 这是产品当前明确划定的范围（代码注释原文：「暂时不做自动获客」）。

## 二、开始前要准备什么

| 项目 | 要不要 | 说明 / 依据 |
|---|---|---|
| **登录账号** | **建议登录** | 页面不登录也能打开（只显示「登录/注册」按钮）；但：① 配置保存到**你的账号**名下（未登录会存进一个 uid=0 的公共桶）；② 「✨ 让 AI 推荐话术」**必须登录**，否则直接报「未登录」。 |
| **用客户端（桌面 App）打开** | **强烈建议** | 平台按钮能不能勾，取决于**客户端检测到的平台登录态**。用普通浏览器打开时，检测不到登录态，平台会全部显示「未登录」。 |
| **先在客户端登记平台登录态** | **要**（想勾平台就得先登） | 「未登录的平台不能勾」——这是设计如此。没登记的平台旁边会给一个「去登记」按钮，点开内置浏览器登录后即可勾选。 |
| **素材 / 图片 / 视频** | **不需要** | 这条线不产出视频、不吃素材，只收集「获客配置」。 |
| **后台配置 AI Key** | **要**（想用「AI 推荐话术」才要） | 没配 Key 时点推荐会提示「AI 未配置（请先在后台上传 Key）」。 |
| **进入「标准模式」** | **要** | 这套命令闸门只在 AGENT 页的**标准模式**下生效。 |

## 三、一步步怎么用

### 第 1 步：打开面板

在 AGENT 页下方输入框里，**一字不差**输入这句话，或直接点下方那个「智能获客」按钮：

```
智能获客
```

- 输入后，右边会弹出一张**「智能获客 · 设置面板」**卡片。
- ⚠️ 这四个字**少一个字、错一个字都不生效**（比如「智能客服」「智能获客功能」都不行），会被回一句「你这句话不在命令表里」。
  - 原因：标准模式是**命令白名单锁死**，且这条命令**没有别名**——只有「智能获客」这一个精确写法。
- 可复制原话（就这一条）：
  - `智能获客`

### 第 2 步：在面板上把 5 项填好

面板从上到下一共 5 块，按顺序填：

1. **① 触达平台（多选）** —— 抖音 / 小红书 / 微博 / 视频号 / B站 / 快手。
   - **已登录的**能勾（旁边有 ✓）；**未登录的勾不动**，点旁边的「去登记」去登录。
2. **② 话术表** —— 一行一条，评论和私信共用。
   - 可以自己点「＋ 加一行」手写；也可以点 **「✨ 让 AI 推荐话术」** 让 AI 按你填的关键词生成 5~10 条。
   - 每条**最多 120 字**，会自动去掉表情符号。
3. **③ 目标人群 / 关键词** —— 1~3 个，逗号分隔。
4. **④ 频控速度** —— 选档位（慢 / 中 / 快 / 极速），或直接改数字。**默认「慢」最稳**。
5. **⑤ 数据来源** —— 线索从哪来（热点聚合 / 平台热榜 / 已有线索池 / 关键词搜索 / 评论抓取 / 用户画像）。
   - ⚠️ 其中「平台热榜 / 关键词搜索 / 评论抓取 / 用户画像」这 4 个目前**只对管理员(Admin)开放**，普通账号勾了能不能拿到数据 **未验证**。

**可直接复制粘贴的原话示例：**
- 打开面板（入口词）：`智能获客`
- 关键词框里填（③）：`装修、二手房、本地`
- 话术正文框里手写（②），例如：`看到你家装修风格挺喜欢的，想了解下大概报价，方便聊聊吗`
- 想放弃当前这单、把面板关掉：`取消` （或 `重新开始` / `重来` / `清空` / `重置` / `不做了` / `算了` / `退出获客`）

### 第 3 步：保存 或 预演

面板底部只有两个按钮：

- **`💾 保存配置`** —— 把当前配置存到你的账号（服务端草稿，刷新/重启不丢）。
- **`👀 预演（只预览，不发送）`** —— 生成一张「**将要执行的动作清单 + 频控节奏**」卡片给你看。
  - 预演卡上会列 7 条：数据来源 / 关键词 / 平台 / 评论话术条数 / 私信话术条数 / 每号每日上限 / 合计上限。
  - 预演卡上有「↩ 返回面板」可直接回去改，不用重填。

**想重来一单：** 再说一次 `智能获客`，会**作废旧配置、开一张新面板**（= 重来）。

## 四、它会产出什么

- **页面卡片**：一张「设置面板卡」和（点预演后）一张「预演清单卡」。就是你在对话里看到的那两张表。
- **服务端草稿**：配置存入你的账号，刷新页面 / 重启都还在，随时回来接着说「智能获客」即可。
- **不会产出**：视频、图片、文件、发布任务 —— 这些都不在本线（本线只收集配置）。

## 五、要多久 / 花多少点数

| 操作 | 耗时 | 点数 |
|---|---|---|
| 打开面板、填表、保存配置 | 即时 | **代码中看不到任何计费调用** ⇒（推断）不扣点 |
| 预演 | 即时（只是把配置拼成一段文字清单） | 同上 |
| 「✨ 让 AI 推荐话术」 | **未验证**（无计时埋点） | 会真实调用一次 AI 文本模型；但该接口代码**明确标注「未过 withBilling（未接计费）」**⇒ 实际是否扣点 **未验证** |

> 说明：本线（保存/预演）的处理函数里没有任何计费代码；只有「让 AI 推荐话术」会真的花钱调模型，而它自己承认还没接计费。所以**到底会不会扣点，我们不敢替你保证**，以实际账单为准。

## 六、出错了怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 回你「你这句话不在命令表里…」 | 入口词没打对（多了字/少了字/换了个词），被标准模式锁死 | 一字不差用 `智能获客`；或直接点下方按钮 |
| 点「保存/预演」没反应 / 被锁死 | 面板提交是走内部协议串的；只要本线草稿还在就会放行（正常不该出）。若真被拦，通常是草稿丢了 | 重说 `智能获客` 重开面板重填 |
| 平台勾不动 | 该平台**未检测到登录态** | 点平台旁的「去登记」，在客户端登录该平台后再刷新检测 |
| 「去登记」点不了（提示需要用客户端） | 你现在是**普通浏览器**，不是桌面客户端 | 用客户端打开 AGENT 页 |
| 推荐话术报「未登录」 | 「✨ 让 AI 推荐话术」**必须登录** | 先登录账号 |
| 推荐话术报「AI 未配置」 | 后台没配 AI Key | 让管理员在后台上传 Key |
| 推荐话术报「AI 没返回可用话术」 | 模型这次没给出可用结果 | 重试一次 |
| 面板怎么点都不动 | 卡在上一单草稿里 | 发 `取消`（清本线草稿），再发 `智能获客` 重来 |

> ⚠️ 本线出错时**不会静默失败**：有问题会直接把原因回给你（形如「智能获客」环节出错：xxx）。

## 七、它不能做什么（边界，别误解）

1. **不会真的发评论 / 私信 / 关注** —— 本轮只配置 + 预演。你把面板填完点保存，**它什么都不会往外发**。
2. **没有「自动获客」** —— 真正去执行的动作（执行器）**还没开发**，代码里只有 TODO 注释。
3. **不产出视频/图片/文案成品** —— 想看成品请用「图片成片 / 图视混剪 / AI 制片 / HTML成片 / PPT成片」等成片线。
4. **不是合规工具** —— 面板里的「频控速度」是**工程参考值，不是平台合规值**。代码注释原文：真实平台风控阈值不公开，这里是「先知道极限能力」用的；极速档**不设上限、风险自担**，平台反垃圾会限流甚至封号。
5. **没登录 = 用不完整** —— 推荐话术必须登录；保存的配置按登录账号归属。
6. **数据来源不全对普通账号开放** —— 其中 4 个来源目前仅 Admin（详见第三步第 5 点）。
7. **私信发送能力当前是「占位」** —— 代码注释标明：`sendPrivateMessage` 现在是 mock，下一版必须先接真。
