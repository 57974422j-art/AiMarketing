# 实验线规划（2026-10-30）

> 本文只做**规划与取舍**，不含实现。目标是让「日报落地页 / HTML 成片」两条成品线**一个字节都不动**，
> 在 `/lab` 这条实验线里把方法论试对，再决定要不要回灌。

---

## 一、先看清两个真实问题（已经用截图证过）

### 问题 A：**中间空了一大块**（不是全黑）

实测 `gen_20261030_004.html`（5 段 · 17.5 秒），逐段播完后截图：

```
每段都是同一种排法：
  标题在 y ≈  60
  图片/图形在 y ≈ 900 起
  ⇒ y = 150 ~ 900 这 **750px 什么都没放**
```

而且图片 `top ≈ 900` + 高度 400+ ⇒ **延伸到 1300+，被 `overflow:hidden` 裁掉下半截**。

### 问题 B：**压字**（图/图形压在文字上）

我自己的 demo 就犯过（锅固定在画面正中，压住标题）。

### 我上一版的解法为什么不行

```
我写的「分区硬约束」：
  上区 0~480    只许放文字
  中区 480~1040 只许放视觉主体
  下区 1040~1220 只许放小字
        ↓
AI 的实际做法：标题放 y=60（在上区，合规）、图放 y=900（也合规）
        ↓
**规则全守住了，结果中间 750px 全空**
```

⇒ 结论：**硬坐标分区只解决"别重叠"，解决不了"别空"，而且会限制设计**。
⇒ 用户判断正确：**这条要删掉**。

## 二、别人怎么做的（video-talkcraft / video-shotcraft / mg-styles-15）

> ⚠️ 许可提醒：`video-talkcraft` 是 **PolyForm Noncommercial**（商用需授权），
> `mg-styles-15` 是 MIT。**取思路，不拷代码**。

### 2.1 他们防"空"的四招（不是靠坐标）

| # | 做法 | 原理 |
|---|---|---|
| **1** | **同屏元素预算** | 规定"一屏放几个元素"（太少会空、太多会挤），不是规定位置 |
| **2** | **12 栏栅格 + 间距令牌** | 元素必须落在栅格上、间距取固定档位 ⇒ **元素天然铺开**，不会全挤在顶部或底部 |
| **3** | **留白锚**（留白必须有理由） | 留白是**刻意**的（为了呼吸/聚焦），不是"没排满" |
| **4** | **让位生命周期** | 元素**依次进场 + 依次退场**，画面一直在变 ⇒ 不会出现"一大片静止空白" |

⇒ 第 3、4 条是关键：**他们要的不是"填满"，是"每一帧都有事发生"**。

### 2.2 他们防"压字"的一招（正是我们需要的）

| 做法 | 说明 |
|---|---|
| **包围盒不相交（bounding box non-intersection）** | 作为**排版自检的一项**（`references/layout.md` 九项之一）。不是预设坐标，而是**排完之后逐个算包围盒**，相交就报错 |

⇒ 这正是用户说的"让它注意不要文字动效互相挤压就行"。
⇒ **约束写成"自检项"，而不是"坐标限制"** —— 这样设计自由，但错了能被抓。

### 2.3 其他值得学的（按对我们的价值排序）

| # | 做法 | 对我们的价值 |
|---|---|---|
| **1** | **每场景一条极缓推拉相机曲线**（`CameraRig`），静止帧结构上不可能出现 | ⭐⭐⭐ 直接治"段落看着是 PPT" |
| **2** | **纯文字镜必配线稿陪衬**（图标 + 方框 + 箭头），文字不裸放 | ⭐⭐⭐ 治"头尾不用素材时很空" |
| **3** | **六式运动承接转场**（不是淡入淡出） | ⭐⭐ 转场有设计感 |
| **4** | **静止帧检测**（机器抓，不靠人看） | ⭐⭐ 可加进我们的自检 |
| **5** | **首镜先做先确认**（先出一条有声单镜预览，确认后再做其余） | ⭐⭐⭐ **省大量无效生成** |
| **6** | **领域定风格 · 中性卡蒙皮**：卡片是中性的，风格从内容推导，**改皮不改运动** | ⭐⭐⭐ **正解"不设行业框框"** |
| **7** | **分段渲染母版制**（改一镜只重渲该段 ±邻段，53 秒出新片） | ⭐⭐ 我们改一次要全渲 |
| **8** | **QA 帧拼 3×4 网格给评审**（省 75% token） | ⭐⭐ 我们自检可以直接用 |
| **9** | **四段式 prompt**：Output spec / Technical route / **Creative seed（只换这里）** / **Signature features（不动）** | ⭐⭐⭐ **风格稳定的根本** |
| **10** | **两轮 make → review → revise**，作者明说「单次运行达不到成片水准」 | ⭐⭐⭐ 我们一直一次就交付 |
| **11** | **字级配音同步**（偏差 20~40ms，动效锚在确切的字上） | ⭐⭐⭐ 差距最大，但最难 |
| **12** | **三重验收**：画面健康（静止段 + 光栅抖动）/ 音效能量 / 独立评审 | ⭐⭐ |
| **13** | **视频容器边框八式**（浏览器窗 / 胶片 / 拍立得 / 图纸），一片一式 | ⭐⭐ 便宜的质感提升 |

## 三、我们该怎么改（三条原则先立住）

### 原则 1：**删掉硬坐标分区，改成"自检项"**

```
❌ 删掉：上区 0~480 / 中区 480~1040 / 下区 1040~1220
✅ 换成（写进提示词，作为"交付前自检"）：
   ① 任意两个**文字块**的包围盒不许相交（相交就重排）
   ② **文字块的包围盒**与**图片/图形的主体框**不许相交（留 ≥24px）
   ③ 图片/图形的 top + 高度 ≤ 画布高 − 40（**不许靠裁切藏住**）
   ④ 每个元素必须是**有意放置**的：要么有对齐依据（栅格/基准线），要么是刻意的留白
```

⇒ 关键变化：**从"限制位置"改成"检查结果"** ⇒ 设计自由度回来了，但错误仍会被抓。

### 原则 2：**"填满"不靠坐标，靠三件事**

```
① 同屏元素预算：一屏 8~14 个元素（少于 8 会空，多于 16 会挤）
② 栅格：12 栏 + 8px 间距令牌 ⇒ 元素自然分布
③ 让位生命周期：本段内至少 3 个元素有"进场 → 停留 → 让位"的完整过程
        ↓
⇒ 画面每一帧都在变，就不会显得空
```

### 原则 3：**风格从内容推导，不做行业模板**

```
❌ 现在的做法：用户在 6 个行业风格里选（暖纸=餐饮 / 霓虹=夜宵）
✅ 改成：
   ① 先让模型看素材，判定"这批素材的气质"（明亮/暗沉、饱和/低饱和、繁密/简洁、写实/抽象）
   ② 据此**派生一组参数**：色温、饱和度、字阶落差、元素密度、动效强度、质感
   ③ 这套参数叫"风格档"，卡片/版式**按它蒙皮，但运动逻辑不变**
        ↓
⇒ 什么行业都能做，因为风格是从内容长出来的，不是从行业选的
```

## 四、实验线要做的（按阶段，每阶段可独立验收）

### 阶段 0 · 止血（0.5 天）

| # | 做什么 | 验收 |
|---|---|---|
| 1 | 删掉硬坐标分区，换成"包围盒不相交"自检 | 提示词里再无 0~480 这类硬数字 |
| 2 | 补"总时长 40~60 秒 / 段数 10~16" | 出片 ≥35 秒 |
| 3 | 补"图片 top+高度 ≤ 画布高−40" | 不再有被裁的图 |

### 阶段 1 · 治空（1 天）

| # | 做什么 | 验收 |
|---|---|---|
| 1 | 同屏元素预算（8~14）+ 12 栏栅格 | 每段元素数在区间内 |
| 2 | 让位生命周期（每段 ≥3 个元素有进场+退场） | 无"整段一个静态排版" |
| 3 | 纯文字段必配线稿（图标+框+箭头） | 首末段不再空 |

### 阶段 2 · 治 PPT 感（1 天）

| # | 做什么 | 验收 |
|---|---|---|
| 1 | 每段一条**极缓推拉**（scale 1.0→1.06，全段匀速） | 静止帧为 0 |
| 2 | 六式转场接手（位移/遮罩/放大/擦除/硬切/形状） | 相邻段转场不同 |
| 3 | 自检加**静止检测**（比对段首/段中/段尾三帧像素差） | 检出率 = 100% |

### 阶段 3 · 治风格不稳（1.5 天）

| # | 做什么 | 验收 |
|---|---|---|
| 1 | 风格改成「参数化推导」（色温/饱和/字阶/密度/动效强度） | 换行业素材，风格自动变 |
| 2 | prompt 改四段式（Output spec / 技术路线 / **创意种子** / **签名特征**） | 换内容只改第三段 |
| 3 | 加一轮**自评返修**（按 rubric 打分，不合格带意见重写） | 首轮不合格率下降 |

### 阶段 4 · 省钱提速（1 天）

| # | 做什么 | 验收 |
|---|---|---|
| 1 | **先出一镜确认**（样板镜 + 单镜预览，确认后做其余） | 废单率下降 |
| 2 | QA 帧拼 3×4 网格看 | 自检 token 降 70% |

### 阶段 5 · 字级同步（2~3 天，最难，最后做）

| # | 做什么 |
|---|---|
| 1 | 口播稿 + 音频 → 字级时间戳（faster-whisper 或 sherpa-onnx） |
| 2 | 动效锚点绑到"第几个字的出现时刻"，而不是"段的第几秒" |

| 不做 | 原因 |

## 六、一句话总结

> **我们的问题是"约束写成了坐标，没写成自检"。**
> 别人的做法是：**给栅格和预算（让它自己排）+ 排完用包围盒自检（错了能抓）**。
> 所以实验线的核心改造是：**删掉硬分区，换成「栅格 + 元素预算 + 让位生命周期 + 包围盒不相交」**。
