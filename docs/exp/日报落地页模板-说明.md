# 「日报落地页」模板 · 说明书（阶段 1 产物，2026-10-12）

> **定位**：**保底模板族**。AI 自由写 HTML 崩了 ⇒ 回落到这里：给一份 JSON（段配置）就出一份**合规** HTML，
> 直接能出片。它不属于"AI 创作"，属于"**受约束的模板 + 参数**"。
> 正本判据见 [`响应式段规范-v1.md`](./响应式段规范-v1.md)；实验全貌见 [`实验总账-日报落地页.md`](./实验总账-日报落地页.md)。

## 1. 三件套

| 文件 | 作用 |
|---|---|
| `temp/_exp/template/daily.mjs` | **生成器**：JSON → 单文件 HTML（自带双模式 + `__seek` + **R11 字数体检**） |
| `temp/_exp/template/daily.sample.json` | 样例配置（4 段：封面 / 双图正片 / 单图正片 / 结尾） |
| `temp/_exp/template/out/hotpot-daily.html` | 生成结果（实测三档全绿） |

## 2. 命令

```bash
# 生成
node temp/_exp/template/daily.mjs temp/_exp/template/daily.sample.json --out temp/_exp/template/out/xxx.html
# 审核（三档画布 + R1~R14）
node temp/_exp/shot.mjs temp/_exp/template/out/xxx.html
# 出片（竖/横各一条；长片建议分块：--maxframes N，崩了再跑一次会**续渲**）
node temp/_exp/film.mjs temp/_exp/template/out/xxx.html --w 720 --h 1280 --dur 13 --tag 竖 --out temp/_exp/out/xxx-竖屏.mp4
```

## 3. 配置字段

| 字段 | 说明 |
|---|---|
| `meta.issue` / `meta.title` | 期号（用在眉标）/ 页面标题 |
| `meta.accent` / `meta.paper` | 强调色（朱红）/ 纸底色 |
| `motion` | **动效档**：`calm`（推近小、错峰慢）/ `normal` / `lively`（推近大、错峰快） |
| `imageDir` | 真图目录（默认 `images/`，图名 `1..N.jpg`） |
| `segments[]` | 段数组（**顺序即时间轴顺序**） |
| `segments[].kind` | `cover`（3.4s）/ `feature`（3.2s）/ `end`（3.2s） |
| `segments[].kicker` / `.stamp` | 眉标（左）/ 印章（右，可省） |
| `segments[].title` | 标题数组，**每行一项**（第 2 行自动加朱红下划块） |
| `segments[].imgs` | 图号数组：**1 张=单图版式；2 张=并列版式**（竖屏左右 / 横屏上下） |
| `segments[].points` | 信息点，最多 3 组 `[大字, 小字]` |
| `segments[].place` / `.form` | 段契约属性（`cover|contain` / `overlay|sticker|vertical`） |

**字数体检（生成时自动打印警告，不静默）**：标题每行 ≤12 字、信息点 ≤3 组、每组大字/小字 ≤8 字、每段 1~2 张图。

## 4. 生成物已内置的合规项（对照 R1~R14）

| 项 | 做法 |
|---|---|
| R1/R11 双模式 | 默认 `data-mode="preview"`：**四段纵向可滚动 + 每段自动循环播放**；`__seek(t)` 一调 ⇒ 切 `film` 叠放出片 |
| R3 字号 | 标签 22px 固定、标题 `clamp(44px,7vmin,92px)`（竖屏 ≥40）、正文 22px |
| R4 纵深 | 横屏信息条 `align-self:end` 沉底（实测横屏覆盖 57%、竖屏 82%） |
| **R5 不压图** | 文字全在图外；图与标题间留 8px 安全距、旋转仅 0.25° |
| R8/R9 | 无外链、无随机；段契约 `section.sec[data-seg][data-start][data-duration][data-place][data-form]` |
| **R13 预览动效** | preview 循环（rAF，错开 0.7s）⇒ **打开就能看见动**（实测 31/80 个元素在动、含 18 处文字） |
| **R14 折行** | 短标签 `white-space:nowrap` + `word-break:keep-all`；`<600px` 窄窗降级列数（实测三档 0 处折行） |
| 动效错峰 | 信息点 `.14/.22/.30`（段内 ~60% 收尾，不留"没就位"的尾巴） |

## 5. 接入 AGENT 的落点（阶段 2 清单，未做）

1. 把生成器搬进引擎（`scripts/video-factory/html-deck/tools/`），输入 = 段配置 JSON（可复用 `film.json` 的形状）；
2. 把 `shot.mjs` 的 R1~R14 检查搬成**出片前闸门**（不合格 ⇒ 返回**具体错误清单**，不出片）；
3. AGENT 页加一条线：入口词 → 选素材 → 选族（日报/赛博…）→ 生成/审核/出片（复用现有成片线骨架）；
4. AI 的职责边界：**选图 + 写少字文案 + 选动效档**（不碰布局与 CSS）；布局由模板负责。

## 6. 未做 / 局限（如实登记）

- 真图尚未接入（当前是渐变占位；`<img src="images/N.jpg">` 的槽位已按图号生成）；
- 只支持 1~2 张图/段、3 类段（cover/feature/end）；无表格/时间线/多图拼贴等更多段型；
- 无配音与字幕（下一层）；未接引擎（阶段 2）；
- `motion` 三档只是参数差（推近幅度/错峰快慢），**没有"换一种动效语言"**；
- 阈值（R4 20% / R5 15% / R12 ≥5 / R13 ≥3 / R14 1.6×）都是按 6 件样本拍的经验值。
