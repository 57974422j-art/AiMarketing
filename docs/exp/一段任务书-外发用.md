# 一段任务书（外发用）—— **一次只做「一段」**

> 为什么要有这份：上次让网页版 AI "一次做全片"，它交了一张 **1 秒的静态海报**（`totalDuration = 1.0`、
> 0 个 `<section>`、最小字号 8.64px）。任务书对了但**颗粒度错了** —— 一次做全片它一定走偏。
> 这份把任务**切到"一段=一屏"**，并给出可自检的硬线。
>
> 姊妹文档：[外发实验包-给其它AI账号.md](./外发实验包-给其它AI账号.md)（风格/分段/压力测试三种玩法）。

## A. 任务正文（复制这段给 AI）

```
【任务】只做「一段」视频画面（一屏），交付**单个 HTML 文件**（CSS/JS 内联，无框架、无构建工具）。
这不是一个网站：不要导航、不要页脚、不要滚动、不要多屏。**一屏 = 一段 = 视频里的一个镜头。**

【画布】同一份页面必须同时适配两个固定画布：竖屏 720×1280 与 横屏 1280×720。

【硬约束·逐条必须满足】
1) 响应式：布局只用 grid / flex / % / aspect-ratio / clamp()。
   禁止用 position:absolute + left/top 去定位布局块。
2) 确定性（这段会被逐帧渲染成视频）：禁止一切网络请求（无外链字体、无 CDN、无 fetch）；
   禁止 Math.random() / Date.now()；禁止会自动播放的无限动画。
   时间轴统一走：window.__seek(t)（t=秒，渲染时从 0 连续给到段末），
   所有视觉变化都由 CSS 变量（例如 --t / --p）算出来；
   **t=0 必须已经是一张完整、可看的静止画面**（不能空白、不能半截）。
3) 字号硬线：正文/标签 ≥22px，注脚 ≥18px。**禁止用 clamp 把最小值压到 22px 以下**。
4) 不许「文字压图」：任何文字不得叠在图片上（除非该文字带 ≥60% 不透明度的色块底衬）。
5) 不许编造数据：所有数字/品牌必须来自【B】给的素材说明；说明里没有的就不写。
6) 全中文；不要声明任何 @font-face。

【素材】见下方【B】。**图片一律用 CSS 渐变占位**（不要引用不存在的文件），
   但在 HTML 顶部注释里写清每个槽位：用途 + 建议比例 + 裁切策略（cover=满屏裁 / contain=不裁）。

【段契约（以后要接进我们的渲染引擎，属性名请一字不差）】
   整段用一个容器：
   <section class="sec" data-seg="段号" data-start="0" data-duration="段秒数"
            data-place="cover|contain" data-form="overlay|sticker|vertical">
   段内所有动效**只由 __seek(t) 驱动**（不许让 CSS animation 自己跑）。

【自检】交付时逐条回答【C】的 8 条，并写明你**最没把握**的地方。
【交付】一个 HTML 全文 + 一段说明。不要压缩包、不要多文件依赖。
```

## E. 真实引擎契约对照（这块是给我方后续"接通"用的，AI 不用管）

我们引擎 `film-to-page.mjs` 真在用的属性（`:667` 每段、`:721` 舞台）：

| 层 | 真实写法 |
|---|---|
| 舞台 | `<div id="stage" data-composition-id="main" data-start="0" data-duration="<全片>" data-fps="25" data-width="<W>" data-height="<H>">` |
| 每段 | `<section class="sec clip st-<结构名>" id="sc<N>" data-start="<起>" data-duration="<时长 + 0.7>">` |
| 语法属性 | `data-sys / data-place / data-form / data-complete` |

## G. 多段版（追加这段即可：要**多屏 + 动效 + 能预览 + 能转视频**）

> 背景（2026-10-12 实测 3 版外发产物）：让 AI 做多段时，它做出了**两个都不能用**的版本 ——
> ① 「时间轴版」= `display:none` 只显示第 1 段 ⇒ **你双击打开只看到一屏**（实测竖屏底部覆盖率 **0%**）；
> ② 「滚动预览版」= 为了让你看见，把 `__seek` 时间轴**扔掉**、改成 `scroll-snap` + 横向滚动 ⇒ **不能拿去转视频**。
> 正解是下面这个**双模式**。

```
【追加要求·多段版】这次做**一条多段成片**（默认 8 段，可按素材 6~12 段），不是一屏落地页。
每段 = 一屏 = 一个镜头；**段与段之间不能靠滚动切换**（出片时是按时间"掐段"）。

★ 双模式（最重要，直接解决"打开只看到一屏"）
  1) 默认 = 预览模式：`<html data-mode="preview">`。此时**所有段按顺序纵向排布**（position:static、可滚动、段间有分隔），
     我双击打开就能从封面一路看到结尾；**任何段都不许默认隐藏**（不许用 display:none 藏起来当"时序"）。
  2) 渲染模式：一旦外部调用 `window.__seek(t)`，自动切 `document.documentElement.dataset.mode = 'film'`，
     此时所有段**叠放在同一张画布上**，由 `data-start` / `data-duration` 决定 t 时刻显示哪一段。
  ⇒ 验收：双击能全看到（预览）；`window.__seek(0)` / `(5)` / `(20)` 各能得到**确定的一帧**（出片）。

★ 段契约（每段都必须有，属性名一字不差）
  <section class="sec" data-seg="1" data-start="0" data-duration="3.2" data-place="cover|contain" data-form="overlay|sticker|vertical">
  段内动效（推入/擦除/叠化/缩放）**只由 __seek(t) 驱动**；t=0 时每段都必须是**完整静止画面**。

★ 图片
  目录用 `images/`：`<img src="images/1.jpg">`；顶部注释给出"图号 → 用途 / 比例 / cover|contain"对照表；
  `<img>` 写 `width`/`height` 免得加载前后跳动；**加载失败要优雅降级**（保留深色底衬，不要把 alt 文字堆在画面上）。

★ 转场
  相邻段允许 **0.5~0.7 秒重叠**（上一段还在、下一段已开始入），不要留黑场。

【自检（多段版必答；答错会被当场抓）】
1. 双击打开**一共能看到几段**？（必须 = 段数；只有 1 段说明没做预览模式）
2. `window.__seek(0 / 5 / 20)` 分别命中第几段？
3. 最小字号 / 最大字号各多少 px？有没有 <22px 的正文或标签？
4. 竖屏主标题 ≥40px 吗？**横屏也不得小于 32px**（别拿 28px 的标题糊过去）。
5. 绝对定位用了几处？（布局块必须 0 处）
6. 每段的 `data-start` / `data-duration` 列出来（必须首尾相接、无缝）。
7. 图片路径是什么？我该把图放到哪个目录、按什么命名？
```

> ⚠️ 反面教训（实测）：某版自检写"横屏主标题 28px，满足硬线" —— **不实**。硬线是**竖屏主标题 ≥40px**；
> 而同一版实测有 **4 处 20px 小字**（信息点标签）低于 22px。**自检要全量报数字，不能只挑达标的说。**

## H. 追加：**文字量**与**动效**（R11/R12 · 2026-10-12 按实测反馈新增）

> 反馈原话：「**字太多了**」「**字体动效有点不足**」。这两条现在都是**硬线**，而且我这边的审核工具会量。

```
【追加·文字量（R11）】每屏文字上限：
  · 主标题 ≤12 字（可拆 2 行，但每行 ≤7 字）；
  · 副文 ≤28 字，**建议直接省略**（宁可少字，不要小字堆叠）；
  · 信息点 ≤3 条，每条 ≤8 字（标签 4~6 字最佳）；
  · 任何文字块不超过 2 行。
  ⇒ 宁可"一张图 + 一句话"，也不要"一段说明文"。

【追加·动效（R12）】每段至少 **4 类**动效，**其中必须包含"文字位移"类**：
  ① 图：缓慢推近/平移（整段持续，不是入场一下就停）；
  ② 标题：**逐行升起 / 擦入 / 逐字浮现**（排版位移，不要只是整块淡入）；
  ③ 装饰：线条生长 / 网格漂移 / 扫描线扫过；
  ④ 信息点：逐个升起（错开 0.15~0.25 秒）。
  ⇒ **只做"整块淡入"不算**；t=0 不得是空白帧（主体轮廓可见即可，允许分段入场）。

【追加·段命名（必须照抄，否则审核工具数不到你的段）】
  段容器**必须**是：<section class="sec" data-seg="1" data-start="0" data-duration="3.2" ...>
  （上一版用的是自己的 class 名，结果"打开只有一屏"这件事我们只能靠肉眼看，机器量不到。）

【追加·自检（在原有 7 条后面再加 3 条，全量报数字）】
 8. 每屏字数：标题 __ 字 / 副文 __ 字 / 信息点 __ 条 × __ 字（有没有超过上限？）
 9. 每段列出动效清单：图动什么、文字怎么进（位移还是仅淡入）、装饰动什么、信息点怎么进？
10. 双击打开可见几段 / 共几段？（必须相等）
```
