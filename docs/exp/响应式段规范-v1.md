## 1. 规范条目（R1~R12）

**R1 一屏一段**：一个 HTML = 一屏 = 一段镜头；不滚动、无导航、无页脚。
（多段成片见 R11：用"双模式"兼顾预览与出片。）

**R2 双画布**：竖 720×1280 与 横 1280×720 都要成立。布局只用 `grid / flex / % / aspect-ratio / clamp()`；
**禁止** `position:absolute + left/top` 定位布局块。

**R3 字号下限**：正文/标签 **≥22px**；注脚 **≥18px**；竖屏主标题 **≥40px**（横屏 ≥32px）。
**禁止** `clamp()` 最小值低于上述数。

**R4 补纵深**：横屏下 40%（y>60%）内容覆盖率 **≥20%**；竖屏下 20%（y>80%）同。

**R5 文字不压图**：文字不得叠在图片上，除非带 **≥60% 不透明底衬**。

**R6 对比度**：正文/底 ≥4.5、次要 ≥3.0、强调 ≥2.0 —— 与引擎 `tools/theme.mjs` 同一口径。

**R7 素材槽位**：图片用 `<img src="images/N.jpg">` + `object-fit`；顶部注释标"用途/比例/cover|contain"；
有真图时不许用渐变假图；加载失败要**优雅降级**（留底衬，不要 alt 文字堆在画面上）。

**R8 确定性**：无网络请求；禁 `Math.random()` / `Date.now()`；禁自动播放的无限动画；
时间轴统一 `window.__seek(t)`。
⚠️ v1.2 修订：**t=0 不得是空白帧**（主体轮廓可见即可）；**允许分段入场**（先前"t=0 必须完全静止"与 R12 冲突）。

**R9 段契约（属性名一字不差）**：
`<section class="sec" data-seg="N" data-start="秒" data-duration="秒" data-place="cover|contain"
data-form="overlay|sticker|vertical">`，动效只由 `__seek` 驱动。
（**这条同时是审核工具的识别依据**：不用这套命名，工具数不到你的段。）

**R10 不许编数据**：数字/品牌/门店/评分必须来自给定素材说明。

**★R11 文字量与双模式（v1.2 新增）**
- 每屏文字上限：**标题 ≤12 字**；副文 **≤28 字且建议省略**；**信息点 ≤3 条 × ≤8 字**；
  任何文字块**不超过 2 行**。理由：用户实测反馈「字太多了」。
- **双模式（解决"双击只看到一屏"）**：
  ① 默认 `<html data-mode="preview">`：所有段**纵向排布、可滚动**，段间有分隔，**任何段都不得默认隐藏**；
  ② 一旦外部调用 `window.__seek(t)` ⇒ 自动切 `data-mode="film"`：段叠在同一画布，按 `data-start/duration` 显示。
- 审核口径：`预览可见段数 == 段总数`。

**★R12 动效强度（v1.2 新增）**
- 每段至少 **4 类动效**，且**必须包含文字位移类**（逐行升起 / 擦入 / 逐字浮现 / 缩放），
  **不能只有整块淡入**。理由：用户实测反馈「字体动效有点不足」。
- 审核口径（自动）：比较 `__seek(0.2)` 与 `__seek(2.0)` 两帧 ——
  **≥5 个元素发生变化** 且 **≥1 处文字发生位移（矩形变化 >2px）**；
  文字"仅淡入"（有效透明度变化 >8%）单独统计、不算位移。

## 2. 验收口径（自动 + 人工）

**自动**：`node temp/_exp/shot.mjs <文件...>`
| 项 | 判定 |
|---|---|
| 溢出 / 越界 / JS 报错 / 外链 | 必须 0（硬） |
| 缺图（`<img>` 未加载） | 报数（引擎闸门①同口径；实验阶段可因"图没放到位"豁免） |
| 字号 | 最小 ≥22、最大（竖屏）≥40 |
| R4 覆盖率 | ≥20% |
| R5 压图 | 0 处 |
| R11 预览 | 可见段数 = 段总数 |
| R12 动效 | ≥5 元素动 + ≥1 处文字位移 |
| 截图 | 每个画幅 2 张：`-preview.png`（打开态）+ `.png`（出片态 t=1.2） |

**人工**：看截图 —— 横屏某一列是否空（见 §4 局限）、竖屏是否挤、文字量是否"字太多"。

## 3. 与真实引擎的接通关系

| 外发（实验契约） | 引擎（真实契约，`film-to-page.mjs`） |
|---|---|
| `<section class="sec" data-seg data-start data-duration>` | `<section class="sec clip st-<结构名>" id="sc<N>" data-start data-duration>`（`:667`） |
| `data-place / data-form` | `data-place / data-form`（另有 `data-sys / data-complete`） |
| 单文件自带 `__seek` | 舞台 `#stage data-composition-id="main" data-width/data-height`（`:721`）+ 运行时统一时间轴 |

⚠️ 引擎**每段窗口多留 0.7 秒**（`OVER = 0.7`，`:659-663`）作转场重叠区 ⇒ 外发 `data-duration` + 0.7 = 引擎值。

## 4. 判据标定记录（"看起来通过"≠"判据跑了"）

| 版本 | 改了什么 | 实测后果 |
|---|---|---|
| v2 | 文字 ∩ 任何渐变层 = 压图 | **误报 46 处**（文字在页面渐变底上） |
| v2.1 | 整页背景层不算图片 | deepseek 剩 4 处（对了）；`<em>` 自带高亮底 ⇒ **误报 1 处** |
| v2.2 | "带文字的元素不算图片" | **漏报**：`figure.slot`（内含 `figcaption`）被放过 |
| v2.3 | 按**直接文本节点**判定 | warmfood 0 / magazine 1 / deepseek 4 —— 与肉眼一致 ✅ |
| v2.4 | 加缺图检测 + 主标题字号 | 抓到 v2/v3 缺图 14 张、v3 有 4 处 20px 小字 |
| v2.5 | 加 R11 预览段数 + R12 动效计数 | 量出"打开可见 3/3"与"动了 13/48" |
| v2.6 | **修动效判据 bug**：`opacity` 不继承到 computed style ⇒ 改累乘祖先；文字动效拆"位移/仅淡入" | 修前会把"父级淡入"当成没动（漏判） |

**已知局限（重要，如实登记）**：
- **R4 是整条带覆盖率，不区分左右列** ⇒ 横屏"某一列空"能被另一列撑过去（warmfood 横屏左列偏空但仍报 48%）
  ⇒ **待做：分列覆盖率**。
- **R11 只认 `section / .sec / [data-seg]`** ⇒ 不用这套命名的页面数不到段（v2 外发稿即如此：报"—/可见 0"）。
- R12 只看"两帧之间变没变"，**不判动效好不好看**（审美仍需人看）。
- 阈值（20% / 15% / ≥5 / ≥1）都是**按 5 件样本拍的经验值**。

## 4.5 v1.3 追加：R13 预览动效 + 两条实测得来的排版安全距

**R13 预览动效（用户实测「我看不到动效，全是固定字」）**
- 病灶：v1 的"双模式"里，**预览态把每段固定在完成态**（`--sp=1`）⇒ 人打开文件看到的是**一堆静止的完成帧**；
  文字动效只存在于"出片态"（`__seek(t)`），而人不会去调 `__seek` ⇒ **等于白做**。
- 现口径：**预览态自动循环播放**（`requestAnimationFrame` 驱动每段各自 0→1 循环、错开 ~0.7s）；
  `window.__seek(t)` 一被调用 ⇒ 立刻停循环、切 `data-mode="film"`（渲染确定性不受影响）。
- 审核口径（自动）：**不调用 `__seek`**，隔 700ms 取两帧，**≥3 个元素在动**才算过。

**R5/R3 的两条排版安全距（实测得来，不是经验谈）**
- **行高不要 <1.12**：中文**行内盒**高度 ≈1.4×字号，行盒若只有 1.03~1.04×字号，行内盒会**溢出**行盒
  ⇒ 与下方图片的**外框**相交 ⇒ 被判"文字压图"（d-daily/e-neon 实测各报 1 处，坐标证实是 20px 级的框重叠）。
- **图片上不要加 >0.3° 的旋转**：旋转会把元素外框撑大（700px 宽 × sin0.5° ≈ 6px，高 1000px 时 ≈9px），
  同样会撞上邻居的框；要用"贴上去"的手感，**留 ≥8px 安全距（margin-top）**比旋转更稳。

**判据自身也修了一处同源 bug（第 5 次"判据必须能证伪"）**
- `opacity` **不会**继承到子元素的 computed style ⇒ 只看"自身 opacity"会把**父级隐藏**的元素当成可见。
  film 态下所有段叠在同一画布、非当前段靠 `.sec{opacity:0}` 隐藏 ⇒ 旧判据把它们全算进来，
  产生"段与段互判压图 + 覆盖率 105%"的假报警。**现口径：累乘祖先**（R5/R4/R12 统一用这个）。
