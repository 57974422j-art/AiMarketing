## 0. 一句话需求（用户原话）

> 「**不是改画面上的，改的是口播**。AI 出 3 条可以选、可以修改。」

- 是 **口播稿**（配音念的），**不是**画面上的大字/字幕。
- AI 出 **3 条**候选（不同角度），用户**选 1 条**，**可手工修改**。
- 改完的这条，**作为逐段口播的唯一来源**。
- **不影响其它线**（图片成片 / 图视混剪 / 日报落地页 / PPT成片 / 素材+AI / AI制片）。

## 4. 三条候选怎么写（prompt 口径，直接抄）

```
你是短视频口播稿写手。素材是一组餐饮/美食实拍。
【素材总结（视觉模型读图所得）】{summary}
【用户给的主题/卖点】{topic 或 "（用户没给 ⇒ 只依据素材，不许自创品牌、不许编数据）"}
【这条片的段落骨架】{planTxt}

请写 **3 条不同角度的口播营销稿**，每条 120~180 字（口播 30~45 秒）：

① 钩子型：第 1 句必须是钩子（≤15 字，用具体细节抓人，不许"超值""必吃""一口上瘾"这类空话）
② 优惠型：把活动说清楚（**只在素材或主题里真的出现打折/活动时才写；没有就换一个角度，绝不许编优惠**）
③ 口碑型：用真实可见的细节立信（现切、卖完就收、几点开门这类）

三条都必须：
· 口语化，能直接念（不要书面语、不要排比句堆砌）
· 第 1 句就能立住（不要"大家好""今天给大家介绍"）
· 结尾给一个落点（到店/留言/收藏，三选一，不要每条都"评论区见"）
· **零 emoji、零表情符号**
· **不许编造数据、不许编不存在的优惠、不许自创品牌名**

只输出严格 JSON：
{"candidates":[{"angle":"钩子型","text":"…"},{"angle":"优惠型","text":"…"},{"angle":"口碑型","text":"…"}]}
```

## 5. 口播切段规则（改 `:589-591` 那一段）

原来是「每段各写一句 ≤18 字」，改成：

```
上面已给定一条完整口播稿（{pitchText}，共 {n} 字）。
请把它**按段落切成 {N} 段**（N = 骨架段数），每段口播写进对应段的 `voice` 字段：
· 按该段时长估算字数（约 4.5 字/秒）；相邻段之间要**语意连贯**（不是各写各的）
· 全部段的 voice 拼起来必须**完整覆盖这条口播稿**（不许多、不许少、不许改意思）
· 可以微调用词以适配段长，但**不许改变承诺的内容**（尤其优惠信息一字不许变）
```

⇒ **核心变化**：口播从"碎句拼接"变成"**整稿切段**"，连贯性由整稿保证。

## 7. 验收标准（做完必须真跑一遍）

1. 走一单 HTML 成片 → 第 2 步点「下一步」→ **出现 film_pitch 卡，3 条候选文字各不相同**；
2. **选第 2 条** → 点「用这条写口播」→ 确认卡上显示的最终稿 = 第 2 条；
3. **手工改几个字**再提交 → 确认卡显示的是**改后的版本**（不是原文）；
4. 出片 → 成片**配音念的是这条稿**（不是原来的碎句拼接）；
5. 把 `voice` 各段拼起来 ≈ 整稿长度（覆盖完整，不多不少）；
6. 素材里**没有优惠信息**时 → 三条候选里**不出现任何"打折/优惠/立减"字眼**。
