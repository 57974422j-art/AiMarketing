## 二、7 种卡型（**AI 会产出**）+ 渲染器支持的 11 种

**AI 会产出的 7 种**（prompt 白名单：`bgimage / title / list / number / compare / chart / end`）。
**渲染器实际支持 11 种**：上面 7 种 + `image` / `video` / `quote`（兜底归一化用）+ **`aivideo`**（★AI 直接成片专用，由 `make.py` 逐镜写入，AI 不会产出）。
**未知卡型一律降级为 `title`**（不再让整镜失败）。

| 卡型 | 用途 | 关键实现 |
|---|---|---|
| `bgimage` | **素材图卡**（主用） | 不裁切（底层放大+模糊+压暗铺满，上层 `contain` 居中）＋ Ken Burns ＋ 大字逐字浮现 |
| `title` | 标题 | 大字逐字浮现 |
| `list` | 要点 | **逐项渐入**，后项出现时前项变暗当上下文 |
| `number` | 大数字 | **0 → 目标递增**（`eif` 表达式） |
| `compare` | 左右对比 | `left/right` + `leftDesc/rightDesc`（2026-09-20 放开） |
| `chart` | 数据条 | 横条按 `value` 比例**生长**（`items:[{label,value}]`） |
| `end` | 结尾 CTA | 主标语 + 行动号召 |

> 另有 `image` / `video` / `quote` 三种**渲染器存在**，但 **AI 不产出**（`image`/`video` 需要本地媒体路径，AI 给不出）。
> 渲染器派发表 `CARDS` 共 10 种；**未知卡型会降级为 `title` 卡**（不会让整片挂掉）。

**3 套主题**：`dark`（深蓝 `0x0a1620`/白/橙）｜`tech`（深青 `0x0b1c2c`/浅蓝白/青）｜`light`（浅纸 `0xf5f2ea`/近黑/红）

## 三、关键机制（这些是"不出错"的护栏）

| 机制 | 作用 |
|---|---|
| **覆盖率门禁** `★VF_GATE_V1` | `sum(subtitle)/文案 < 80%` → **不给「确认出片」**（避免"只念一部分"） |
| **字幕兜底** `★VF_SUBFILL_V1` | 覆盖率不足时，**代码把文案按顺序切成 N 段填入每镜 subtitle**（只增不减、不动卡型与画面） |
| **扩镜** `★VF_SHOTCOUNT_V1` | AI 镜数 < 目标×0.7 → **按目标镜数重排**（切 N 段 + 保留解说卡骨架 + 其余素材图轮换）→ 每镜回到 ~5 秒 |
| **切段限长** `★VF_SPLIT2_V1` | 每段 ≤45 字；长句按「，、；」二级切；段数不足时**劈最长段**（不再补空段） |
| **画布跟素材走** `★VF_SIZEFIT_V1` | 素材最大边 <1920 → 输出 720p、<1280 → 540p（**不放大就不糊**） |
| **低清图过滤** `★VF_HDONLY_V2` | 短边 <640 的图不进画面（发布抽帧 `frame_*` 常见 640×304）**只过滤、不重排** |
| **素材抽样** `★VF_MATSPREAD_V1` | 封面图优先 + 按文件名批次分组 + 组间轮转交织（治"取到的全是同一批相似帧"） |
| **上传精确取** `★VF_UPLOAD_V2` | 前端带刚上传的文件名 → 按名精确筛（找不到才回退"最近上传"）；**上传几张就用几张** |
| **pick 均匀** `★VF_PICKSPREAD_V1` | "用得最少优先 + 相邻不重复"（治"6 镜只用 2 张图"） |
| **示例词清理** `★VF_NOCLONE_V1` | AI 照抄 prompt 示例文字（`效率翻10倍`等）→ 一律清空（治"每条画面大字都一样"） |
| **JSON 容错** `★VF_PICKFIX_V1` / `★VF_SHOTGEN_V1` | 正则修 `"pick":图1` → 非法 JSON 自动**重试一次**（回喂"只修 JSON"） |
| **门禁逃生口** | 分镜失败时卡片给「🔄 重试分镜」/「▶️ 先出字幕版（无素材画面）」 |

| `[表单] aspect=… dur=… voice=… source=… topic="…"` | 表单参数解析结果 |

| `[画布] 素材最大边 Npx → 输出 WxH（不放大）` | **画布分辨率跟素材走** |
| `[素材配比] 时长Ns → 取图上限 N 张（仓库实际 N，可用 N）` | 取图数量（≈每 30 秒 5 张） |
| `[清晰度] 低清图过滤：N → M 张（短边 < 640 的不进画面）` | **有图被过滤才打印**（没打印=没图可滤） |
| `[上传] 本次成片只用【最近上传】的素材` | 走了"上传素材"分支 |
| `[上传] 精确使用刚上传的 N/M 张：…` | **按前端传来的文件名精确命中**（`M/M` 最理想） |

| `[分镜] N 镜` | AI 排出的镜数 |
| `[扩镜] AI 只排 N 镜（目标 M）→ 按目标重排 K 镜（每镜约 X 字 ≈ Y 秒）` | **镜数不足被代码重排**（治"一镜太长"） |
| `[分镜重试] 首次输出不合法 → 回喂修 JSON` / `成功 N 镜` | JSON 非法时自动重试一次 |

| `[字幕兜底] AI 只覆盖 X% → 按顺序切成 N 段填入 → 覆盖 Y%（预计 Z 秒）` | 覆盖率不足时的**确定性兜底** |

| `[BGM] 已下载音乐库曲目 -> bgm_xxx.mp3` | 自动配乐命中 |
| `[入队] MAKE_VIDEO_TASK:vf…` | 出片任务入队 |

## 七、★ AI 直接成片（「🎨 全部 AI 生成」）—— 2026-09-20 接通

> 用户定案：「AI **仍然看素材**写文案分镜，然后交给 AI 去处理」「看了素材让它自己决定」「**不要修改，别把现在素材成片给搞乱了**」

### 8.1 三种画面来源（**不要用 A/B/C 缩写**）

| 来源 | 画面怎么来 | 30 秒片成本 |
|---|---|---|
| **🎞 素材合成** | 你仓库的图 + Ken Burns 推拉 | **≈ 7 点**（按文案字数） |
| **✨ 素材 + AI 混合** | （**未实现**，见方案第 2 步） | — |
| **🎨 全部 AI 生成** | **每一镜都调 AI 生视频**（MiniMax H3） | **≈ 1500 点**（按秒 × 50） |

### 8.2 链路（**与素材合成在起草阶段完全相同**，只在最后一处分叉）

```
取素材 → 素材摘要 → 写文案 → 排分镜 → 定画幅 → 定画布     ← 两条路【完全一样】
                                   ↓
                       分叉：make.py 收到 --source ai
                                   ↓
   tts.py（配音，回填每镜真实时长）→ 【新】逐镜调 MiniMax H3 → 落 clips/shotNN.mp4
                                   ↓
                    render.py 的 `aivideo` 卡型（铺视频 + 字幕 + 压暗）
```

**关键点**：
- **素材的作用是"给 AI 依据"**（AI 因此知道你在卖什么），**不是"把素材图用进片子"**。
  AI 出片 = **AI 画全新画面**。想要"让素材图动起来"是**另一个功能（图生视频）**。
- **必须在配音之后**调 H3 —— 因为 H3 只支持**整数秒**（4~15s），要按每镜配音时长取整。
- **H3 调用在 `make.py`（Python）**，与 `src/lib/minimax-h3.ts` **刻意同构**（同环境变量、
  同"中转优先 → 官方降级"、同 `/v2/video_generation` + 600s 轮询、"内容问题不降级"）。

### 8.3 护栏（AI 模式专有）

| 护栏 | 做法 |
|---|---|
| **报价与实扣同源** | 卡片 `cost` 与 `make_ai_video` 都用 `秒 × 50`（**曾出现"卡片报 7 点、实扣 1500 点"**） |
| **单镜失败不整片挂** | 该镜**保留原样**（`type` 仍是 `bgimage` → `render.py` 用素材图顶上） |
| **零成功自动回退** | 全是失败 → `make.py` 整个退回素材合成 |
| **重跑省钱** | 已生成过的镜（`type='aivideo'` 且 `src` 存在）**直接复用** |
| **时长对齐** | 片段短于镜时长 → `setpts` 轻微放慢（≤1.35 倍）+ `-stream_loop` 循环兜底 |
| **不叠 Ken Burns** | 画面本身在动，再推拉会晕 |
| **单镜 `-an`** | AI 片段自带音轨 → 静音，声音统一由 `mux_audio` 铺"配音 + BGM" |
| **画面描述不许有字** | prompt 里明确要求"画面里不要出现任何文字"（文字归字幕层） |
| **前端防误导** | AI 模式下：「自动画幅」置灰+强制竖屏、「我上传素材」置灰、`uploaded` 不提交 |
| **诚实文案** | 卡片不再说"画面用你的素材"；确认按钮标「约 50 点/秒」「· 🎨 AI 画面」 |

### 8.4 AI 模式专有日志

| 日志 | 含义 |
|---|---|
| `[画面来源] 全部 AI 生成（MiniMax H3）—— 仍按素材写文案/分镜/画幅，画面改由 AI 逐镜生成` | 起草阶段确认走了 AI 模式 |

### 8.5 ⚠️ 「画面来源」有【两套 UI】——改之前必看（否则改了看不到效果）

`page.tsx` 有**两处**画面来源界面，由后端 `step` 决定显示哪个：

| 后端 `step` | 前端显示 | 出现时机 | 代码位置 |
|---|---|---|---|
| **`form`** | **`VideoFormCard`**（完整表单：画面来源 / 画幅 / 时长 / 音色 / 主题 / BGM / 风格，一次提交） | **只有"第一句起稿"且没有草稿时** | `route.ts:2726 if(!vd)` → L2751；`page.tsx:2236` → 组件 L469-660 |
| **`source`** | **内联卡片**（画面来源 4 按钮 + 画幅 3 按钮） | **已有草稿后的一切交互** | `route.ts:2793/2802/2812`；`page.tsx:2267-2300` |

**⚠️ 草稿是持久化的**（`saveVfDraft` 存 DB）→ **做过一条成片后，`VideoFormCard` 可能再也不出现**。
**→ 改"画面来源"相关 UI，必须【两处都改】。**

### 8.6 ⚠️ "前端改了不生效"怎么自查

服务器上三类东西生效方式不同：

| 类型 | 生效方式 | 要不要构建 |
|---|---|---|
| **Python 脚本**（`scripts/video-factory/*.py`） | `git reset --hard` **立刻生效** | ❌ 不需要 |
| **后端**（`src/app/api/**/route.ts`） | `bash scripts/deploy-server.sh` 重建 | ✅ 需要 |
| **前端**（`src/app/**/page.tsx`） | 同一次构建 | ✅ 需要 |

**关键判断**：**后端是新的、前端是旧的 → 说明 `page.tsx` 的改动没进那次提交**（同一次 build 不可能只更新一半）。
**自查（不改任何东西）**：
```powershell
git status --short          # page.tsx 是否还在未提交列表？
git log --oneline -3        # 提交里有没有它？
```
