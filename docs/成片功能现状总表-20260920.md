## 二、7 种卡型（AI 可产出）+ 渲染要点

| 卡型 | 用途 | 关键实现 |
|---|---|---|
| `bgimage` | **素材图卡**（主用） | 不裁切（底层放大+模糊+压暗铺满，上层 `contain` 居中）＋ Ken Burns ＋ 大字逐字浮现 |
| `title` | 标题 | 大字逐字浮现 |
| `list` | 要点 | **逐项渐入**，后项出现时前项变暗当上下文 |
| `number` | 大数字 | **0 → 目标递增**（`eif` 表达式） |
| `compare` | 左右对比 | `left/right` + `leftDesc/rightDesc`（2026-09-20 放开） |
| `chart` | 数据条 | 横条按 `value` 比例**生长**（`items:[{label,value}]`） |
| `end` | 结尾 CTA | 主标语 + 行动号召 |

> 另有 `image` / `video` / `quote` 三种**渲染器存在**，但 **AI 不产出**（`image`/`video` 需要本地媒体路径，AI 给不出）。
> 渲染器派发表 `CARDS` 共 10 种；**未知卡型会降级为 `title` 卡**（不会让整片挂掉）。

**3 套主题**：`dark`（深蓝 `0x0a1620`/白/橙）｜`tech`（深青 `0x0b1c2c`/浅蓝白/青）｜`light`（浅纸 `0xf5f2ea`/近黑/红）

## 三、关键机制（这些是"不出错"的护栏）

| 机制 | 作用 |
|---|---|
| **覆盖率门禁** `★VF_GATE_V1` | `sum(subtitle)/文案 < 80%` → **不给「确认出片」**（避免"只念一部分"） |
| **字幕兜底** `★VF_SUBFILL_V1` | 覆盖率不足时，**代码把文案按顺序切成 N 段填入每镜 subtitle**（只增不减、不动卡型与画面） |
| **扩镜** `★VF_SHOTCOUNT_V1` | AI 镜数 < 目标×0.7 → **按目标镜数重排**（切 N 段 + 保留解说卡骨架 + 其余素材图轮换）→ 每镜回到 ~5 秒 |
| **切段限长** `★VF_SPLIT2_V1` | 每段 ≤45 字；长句按「，、；」二级切；段数不足时**劈最长段**（不再补空段） |
| **画布跟素材走** `★VF_SIZEFIT_V1` | 素材最大边 <1920 → 输出 720p、<1280 → 540p（**不放大就不糊**） |
| **低清图过滤** `★VF_HDONLY_V2` | 短边 <640 的图不进画面（发布抽帧 `frame_*` 常见 640×304）**只过滤、不重排** |
| **素材抽样** `★VF_MATSPREAD_V1` | 封面图优先 + 按文件名批次分组 + 组间轮转交织（治"取到的全是同一批相似帧"） |
| **上传精确取** `★VF_UPLOAD_V2` | 前端带刚上传的文件名 → 按名精确筛（找不到才回退"最近上传"）；**上传几张就用几张** |
| **pick 均匀** `★VF_PICKSPREAD_V1` | "用得最少优先 + 相邻不重复"（治"6 镜只用 2 张图"） |
| **示例词清理** `★VF_NOCLONE_V1` | AI 照抄 prompt 示例文字（`效率翻10倍`等）→ 一律清空（治"每条画面大字都一样"） |
| **JSON 容错** `★VF_PICKFIX_V1` / `★VF_SHOTGEN_V1` | 正则修 `"pick":图1` → 非法 JSON 自动**重试一次**（回喂"只修 JSON"） |
| **门禁逃生口** | 分镜失败时卡片给「🔄 重试分镜」/「▶️ 先出字幕版（无素材画面）」 |

## 四、TTS（4 个引擎 + 顺序可配）

| 引擎 | 端点 | 音色 | 状态 |
|---|---|---|---|
| **百炼** `dashscope` | `services/aigc/multimodal-generation/generation` + **`qwen3-tts-flash`**（**同步**，不能带 `X-DashScope-Async`） | `Cherry/Serena/Ethan/Chelsie` | ✅ 实测 ok（音质最好） |
| **Minimax** `minimax` | `/v1/t2a_v2`（可用同一 `MINIMAX_API_KEY`；可指向中转） | `female-*` / `male-*` | ✅ 实测 ok |
| **硅基** `silicon` | `/v1/audio/speech` | `FunAudioLLM/CosyVoice2-0.5B:alex` | ✅ 实测 ok |
| **火山** `volcano` | `openspeech/v3/tts/unidirectional` | `zh_female_*_bigtts` | ✅ 实测 ok（**已从默认链移出**，可显式启用） |

- **默认顺序**：`dashscope,minimax,silicon`（`.env.local` 里 `VF_TTS_ORDER` 可改）
- **音色映射**：表单选的是**百炼 id**（`longxiaochun`…），各引擎自己映射（百炼→qwen3 / →Minimax / →火山）
- **失败表现**：全部引擎失败 → `[TTS] ⚠️ 全部引擎都失败…` + `[MAKE] ⚠️ 无配音，出无声片`（**成片只剩 BGM**）

## 五、★ 日志速查（看到某行就知道它在说什么）

### 起草阶段（`chat/route.ts`，前缀 `[VF]`）
| 日志 | 含义 |
|---|---|
| `[入口] msg="…" vfIntent=… 内存草稿=… 自由模式=… 任务词=…` | 状态机入口判定（意图/草稿/模式） |
| `[表单] aspect=… dur=… voice=… source=… topic="…"` | 表单参数解析结果 |
| `[画幅] 判定=landscape（横N/竖N/方N，探测N张） 时长=…s` | **按素材判横竖**（横多→横屏） |
| `[画布] 素材最大边 Npx → 输出 WxH（不放大）` | **画布分辨率跟素材走** |
| `[素材配比] 时长Ns → 取图上限 N 张（仓库实际 N，可用 N）` | 取图数量（≈每 30 秒 5 张） |
| `[清晰度] 低清图过滤：N → M 张（短边 < 640 的不进画面）` | **有图被过滤才打印**（没打印=没图可滤） |
| `[上传] 本次成片只用【最近上传】的素材` | 走了"上传素材"分支 |
| `[上传] 精确使用刚上传的 N/M 张：…` | **按前端传来的文件名精确命中**（`M/M` 最理想） |
| `[文案] AI 写 N 字（目标 M）` → `[压缩] N → M` / `[硬截] → N` / `[扩写] N → M` | 文案字数控制（目标 = 时长×4.5） |
| `[分镜] N 镜` | AI 排出的镜数 |
| `[扩镜] AI 只排 N 镜（目标 M）→ 按目标重排 K 镜（每镜约 X 字 ≈ Y 秒）` | **镜数不足被代码重排**（治"一镜太长"） |
| `[分镜重试] 首次输出不合法 → 回喂修 JSON` / `成功 N 镜` | JSON 非法时自动重试一次 |
| `[覆盖率] subtitle N 字 / 文案 M 字 = X%` | **字幕覆盖率**（门禁看它，≥80% 才放行） |
| `[字幕兜底] AI 只覆盖 X% → 按顺序切成 N 段填入 → 覆盖 Y%（预计 Z 秒）` | 覆盖率不足时的**确定性兜底** |
| `[分镜门禁] N 镜 / 覆盖 X% → 不给确认出片` | **拦下了**（卡片会给"重试/字幕版"两个按钮） |
| `[概要] 图N张 镜N个 风格=… 画幅=…(WxH) 配音=… 时长≈N秒` | **一条看全本次参数**（最省事的检查点） |
| `[起草] 图N张 镜头N个 主题="…" 素材摘要=…` | 起草完成 |
| `[分镜构成] bgimage,title,list,…` | **本条用了哪些卡型** |
| `[BGM] 已下载音乐库曲目 -> bgm_xxx.mp3` | 自动配乐命中 |
| `[入队] MAKE_VIDEO_TASK:vf…` | 出片任务入队 |

### 渲染阶段（`render.py` / `tts.py` / `make.py`）
| 日志 | 含义 |
|---|---|
| `[VF] 底板色跟随素材: 0x…` | 主色底板（取前 3 张素材平均色） |
| `[VF] ffmpeg=… 字体=…` | 环境自检（字体通常是 `NotoSansCJK-Regular.ttc`） |
| `[VF] 第 N 镜 OK  <卡型>  <时长>s -> shotNN.mp4` | 逐镜渲染成功（**带时长**，可看节奏） |
| `[VF] ⚠️ 未知配方卡「x」→ 降级为 title 卡` | AI 自造卡型被**降级**（不会整片挂） |
| `[VF] 拼接完成 -> …（共 N 镜 X 秒）` | 拼接完成 + **总时长** |
| `[VF] 字幕已烧入 -> …/subs.ass (字号 N)` | 字幕烧录（`.ass` 卡拉OK；失败回落 SRT） |
| `[VF] 混音：人声 + BGM（BGM 音量 0.12，-stream_loop 循环铺底）` | 混音分支（另有"仅人声"/"仅 BGM"） |
| `[VF] ✅ 成片: …` / `[MAKE] ✅ 成片: …（N MB）` | 出片成功 |
| `[TTS] 引擎=dashscope`（或 minimax/silicon/volcano） | **实际用了哪个配音引擎** |
| `[TTS] 音色映射: longxiaochun（百炼）→ Cherry（qwen3-tts）` | 音色跨引擎映射生效 |
| `[TTS] ❌ 第 N 镜配音失败: …` / `⚠️ 全部引擎都失败` | 配音失败（会出无声片） |
| `[MAKE] ⚠️ 无配音，出无声片` | 确定无声（只剩 BGM） |
