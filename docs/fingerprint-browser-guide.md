# 指纹浏览器发布指南

> 最后更新：2026-07-23
> 记录抖音自动发布（指纹浏览器）的架构、流程与已知坑。发布脚本本体：`electron/fp-templates/douyin-publish.js`（v5）。

## 1. 发布跑在哪（架构）

- **真发布在 Electron 桌面端**，不在服务器：
  - 脚本：`electron/fp-templates/douyin-publish.js`（1042 行，实际干活）
  - 调用方：`electron/main.js`（`executeDouyinPublish(instance.page, params, log)`）
  - 浏览器视口/窗口在 `electron/main.js` 的 `launchPersistentContext` 里设置
- ⚠️ **服务器那套是 mock**：`src/lib/automation/fingerprint-browser.ts` 直接返回"发布成功"什么都不做，**不能用来判断真实发布结果**。真实发布只发生在你电脑上的 Electron 客户端。
- 日志 **不落盘**：只显示在 Electron 客户端的发布面板（运行一次后 UI 上那段 `logs`），或 Electron 启动控制台。卡住时看那段日志定位。

## 2. 发布流程（7 步）

1. 导航到 `creator.douyin.com/creator-micro/content/upload`
2. 上传视频（file input）
3. 等待转码 + 进入编辑页（检测「封面」区域）
4. 填标题 + 正文
5. 加话题
5.5 设位置（无则跳过）
6. 选封面（竖 3:4 + 横 4:3，自定义图走"上传封面"）
7. 发布（`publishNow!=='false'` 才点「发布」；否则存草稿）

## 3. ⚠️ 已知坑（按出现频率）

### 坑 A：视口太小 → 发布键点不到（2026-07-23 已修复）
- **现象**：1280×800 下编辑页右侧/底部「发布」键在布局视口之外，脚本 `isVisible()` 判不可见就不点，兜底 `click('button:has-text("发布")')` 也因布局失败 → "请手动点击"。全屏也看不到、还有滚动条。
- **修复**：`electron/main.js` 第 318 行 `viewport: { width: 1280, height: 800 }` → `viewport: { width: 1920, height: 1440 }`，并加 `--window-size=1920,1440`。
- **生效条件**：改完须 **重启指纹浏览器**（关掉重开）才生效。只改源码、不重新打包即可（客户端从源码跑）。

### 坑 B：草稿模式假成功（待修）
- **现象**：队列任务的 `publishNow` 为 `false` 时，脚本 step7 只点「保存草稿」就 return，但返回 `{ success: true, needConfirm: true }`；批处理 `if (res.success)` 无视 `needConfirm`，把草稿算成 ✅，误报"发布成功"但视频没发。
- **根因**：`page.tsx` 队列里 `params.publishNow = String(task.publishNow)`；任务创建时 `publishNow: formPublishNow`，由「立即发布 / 仅草稿」切换钮决定。加队列时若停在「仅草稿」就变草稿。
- **修复方向（待做）**：批处理改成 `if (res.success && !res.needConfirm)` 才算 ✅；队列 UI 对草稿任务显示"已存草稿"而非绿色 done。
- **用户自查**：加任务到队列前确认切换钮是「立即发布」。

### 坑 C：封面自定义图失效（待修）
- **现象**：封面弹窗里 `⚠️ 未找到上传封面按钮` 出现两次（竖/横），自定义 png 没传上去，用的是抖音默认帧。
- **根因**：脚本里"上传封面"按钮选择器对不上抖音这版。
- **修复方向（待做）**：修选择器，或匹配不到时明确告警"自定义封面未生效，用了默认帧"，别静默失败。

### 坑 D：指纹浏览器滚轮问题（独立环境层）
- 若页面/弹窗需滚动而指纹浏览器滚轮坏了，会间接导致找不到元素。这与上面脚本 bug 无关，需单独在指纹浏览器里验证滚动是否正常。

## 4. OpenCV / 指纹识别有没有帮助

- **OpenCV（图像定位元素）**：能抗抖音改版，但杀鸡用牛刀；更轻的替代是文本定位 + 更稳等待 + 失败截图。
- **指纹识别（浏览器指纹伪装）**：只防封号，与"脚本卡住/假成功"无关。
- 本次问题（视口 + 草稿误报）都不靠它们解决。

## 5. 排障清单

1. 先看发布面板日志，确认走到 step7 的哪一句。
2. 是「草稿模式」→ 检查「仅草稿」是否误选（坑 B）。
3. 是"未找到发布按钮 / 请手动点击"→ 多半视口/遮罩问题（坑 A，确认已重启浏览器生效）。
4. 封面不是你选的图 → 坑 C。
5. 元素找不到且页面滚不动 → 坑 D（滚轮）。
