> 「数字人不应该跟网页制作那套混在一起，**它应该是单独状态机、呼出页面不一样**。

## 3. 命令词 + 状态机

**命令词**（登记到 `src/lib/agent/standard-commands.ts` 命令表，`kind:'machine'`）：

```
text: '数字人'
alias: ['数字人口播', 'AI主播', '数字人视频', '数字人播报']
```

**状态机 3 步**：

```
dh_photo   → 选照片（仓库候选 + 上传入口）
dh_copy    → 贴文案（显示字数 / 预估时长 / 报价）
dh_running → 生成中（后端异步 + 前端轮询）
dh_done    → 交付（视频链接 + 已存个人仓库）
```

**协议串**（独立前缀，不要和 `VF_FORM` / `VF_FILM_FORM` 混）：

```
VF_DH_FORM:{"at":"photo","name":"xxx.jpg"}
VF_DH_FORM:{"at":"copy","script":"…","res":"480P"}
VF_DH_TASK:{"id":"…"}
VF_DH_DONE:{"url":"…","name":"…"}
```

## 4. 卡片设计（`VfDhCard`，全新）

### 第 1 步 `dh_photo`

```
┌────────────────────────────────────┐
│ 🤖 数字人口播 · 第 1 步 / 共 2 步   │
├────────────────────────────────────┤
│ 选一张人像照片（单人 · 正面 · 清晰）│
│  ┌────┬────┬────┐                  │
│  │ 01 │ 02 │ 03 │  ← 仓库图片缩略图 │
│  └────┴────┴────┘                  │
│  [⬆️ 上传照片]                      │
├────────────────────────────────────┤
│ 提示：整张脸要清楚，别太远、别侧脸   │
└────────────────────────────────────┘
```

- **必须给"上传照片"**（用户仓库常是商品图，没有人像）
- 缩略图来源：`listRepoMaterials` 里的 `kind==='image'`（**只列图，不列视频**）
- **不要做"多选/勾选/上限/拼版"** —— 那是成片卡的东西，这里只要**单选一张**

### 第 2 步 `dh_copy`

```
┌────────────────────────────────────┐
│ 文案（要念出来的话）                │
│ ┌────────────────────────────────┐ │
│ │                                │ │
│ └────────────────────────────────┘ │
│ 约 128 字 · ≈ 32 秒 · 预计 1600 点  │
│ [🔊 试听]        [🚀 开始生成]      │
└────────────────────────────────────┘
```

- 字数 → 时长：**约 4 字/秒**（与成片线同口径即可，不必精确）
- 报价 = `秒数 × 每秒点数`，**480P 与 720P 分开**（见 §6）

### 第 3 步 `dh_running` / `dh_done`

- 生成中：显示"已等待 N 秒"，**不阻塞**（可离开页面）
- 完成：视频播放器 + 「存入个人仓库」（已有）+ 「再来一条」

## 5. 照片合规把关（关键，避免白花钱）

提交前**必须先调 `wan2.2-s2v-detect`**（同步接口）：

- 通过 ⇒ 拿 `face_bbox` 继续
- 不通过 ⇒ **立刻告诉用户"这张不行：<原因>"，不扣点、不提交**

⚠️ 现有 `wanS2vSubmit` 里 detect 是"失败就跳过"（`catch` 掉了）—— **本线必须改成"失败就拦住"**（可以在本线自己先调一次 detect，再调提交）。

## 6. 计费（用户已默认：按秒）

真实成本（百炼官方）：

```
480P：$0.071677/秒  ⇒ 30 秒 ≈ ¥15
720P：$0.129018/秒  ⇒ 30 秒 ≈ ¥27
```

- **默认 480P**，720P 让用户选（价格翻倍，必须明示）
- **报价 = 实扣**（同一个秒数算两次，不许两套算法）
- 扣点用现有 `TOKEN_COSTS.DH_VIDEO` 或新建常量，**同一处定义**

## 7. 已知的三个坑（照这个改，别重新踩）

| 坑 | 现状 | 要做 |
|---|---|---|
| **`duration: 5` 写死** | `ai-providers.ts:1073` 传了 `parameters:{duration:5}` | 官方文档说**时长由音频决定** ⇒ **不要传 `duration`** |
| **detect 带了 Async 头** | `ai-providers.ts:1061` 给同步接口带了 `X-DashScope-Async` | detect 必须**不带**这个头 |
| **地域必须是北京** | 文档原文："仅适用于华北2（北京）" | 调用失败先看 key 地域；本线报错话术里要写清这句 |

> 这三个是**底层函数的修正**，可以在本单里顺手改（属于 SDK 层，不是"别的线的代码"）。
