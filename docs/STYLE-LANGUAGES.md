# 设计语言库（给 AI 设计用的"风格说明书"）

> 用途：日报线与 HTML 成片线出页时，把这套语言注入提示词 ⇒ AI 按选定风格排版。
> 原则：**只给方向和参数，不锁版式**（每单仍由 AI 自己想，不套模板）。
> 写法：每种风格给「可执行的参数」，不是形容词堆砌。

---

## 为什么需要这个文件

现状（实测）：

```
提示词里只有"约束"（下边界1180 / 遮罩≤60% / 铺满 / 字号档）
        ↓
**没有一条审美方向**
        ↓
结果：几十单出来风格几乎一样（暖色 + 大字 + 深色）
```

⇒ AI 有设计知识，但**没被要求用**。这份文档就是那份"要求"。

---

## 一、风格的六个可调维度（所有风格都由这六项描述）

| 维度 | 取值 | 说明 |
|---|---|---|
| **palette** | 底色 / 主色 / 强调色 / 文字色（给具体色值） | 最决定观感 |
| **type** | 字体族 / 字重 / 字距 / 字号落差 | 决定"气质" |
| **layout** | 居中 / 左对齐 / 网格 / 满幅 / 大留白 | 决定"结构感" |
| **density** | 元素数 / 装饰文字数 | 决定"厚不厚" |
| **motion** | 淡入 / 遮罩掀开 / 硬切 / 位移 / 缩放 | 决定"节奏" |
| **finish** | 颗粒 / 暗角 / 半调 / 套印 / 无处理 | 决定"质感" |

⇒ 六项定死，AI 就有一个明确的"框"，但版式仍自由。

## 二、六种风格（按适用场景）

### 1. 暖纸宋体（中式高端餐饮）★ 当前默认

```yaml
palette:  底 #F1E7D6 · 主 #16100C · 强调 #A62B1F · 金 #C0955A
type:     Noto Serif SC 900 / 字距 0.03em / 字号落差 8 倍
layout:   左右留白 52px · 标题左上 · 竖排装饰贴边
density:  高（每屏 12~16 处文字，含竖排/手写/时间戳/胶囊）
motion:   easeOutCubic 淡入 + 上浮 30px
finish:   胶片颗粒 5% + 暖色暗角
适合:     火锅/烤鸭/私房菜/老字号
关键词:   宋体 · 朱红 · 暖纸 · 竖排 · 印章
```

### 2. 瑞士网格（设计感/年轻品牌）★ v6 采用

```yaml
palette:  底 #0B0B0B · 文字 #F2F2EC · 强调 #FFE500 · 灰 #6E6E68
type:     Inter / 无衬线 900 / 字距 -0.045em / 字号落差 14 倍
layout:   严格左对齐 · 可见 12 栏网格线 · 大留白（内容只占左侧 1/3）
density:  中（每屏 8~12 处，但**装饰极少**，靠字号落差撑）
motion:   clip-path 遮罩掀开 + 急停曲线（前 60% 走完 90%）+ 硬切黑场
finish:   无颗粒 / 无阴影 / 只用色块与 1px 细线
适合:     咖啡 / 精酿 / 烘焙 / 买手店 / 设计品牌
关键词:   无衬线 · 荧光黄 · 左对齐 · 网格可见 · 反色落版
```

### 3. 莫兰迪灰调（温柔/女性向）

### 4. 双色套印（复古印刷/老海报）


## 三、注入提示词的写法（关键）

不要只写风格名，要**给出该风格的 3~5 条硬特征**：

```
【本次设计风格 · 瑞士网格】
· 底色纯黑 #0B0B0B，强调色荧光黄 #FFE500，只用这两种颜色 + 米白文字；
· 全部左对齐，不要居中；内容只占左侧 1/3，右侧留空；
· 标题用超粗无衬线，字距收紧到 -0.04em，字号落差拉到 10 倍以上；
· 数字单独放大（如 23 / 32 / 5 秒），当视觉元素用；
· 动效用遮罩掀开（clip-path），不要缓慢淡入；最后一屏可整屏反色；
· 不加阴影、不加渐变、只用 1px 细线和色块。
```

⇒ 这才是 AI 能执行的东西。

---

## 四、怎么让它"越用越准"

```
① 每次出片时记下「用了哪个风格」+ 用户是否满意（👍/👎）
② 满意的风格 ⇒ 提高默认权重
③ 不满意的 ⇒ 记录原因（太冷/太花/字太小…）⇒ 反过来修正该风格的特征描述
```

⇒ 这份文档是**活文档**，不是一次写完就锁死。

---

## 五、和"不锁版式"的关系（重要边界）

```
风格库给的是：**六维参数**（配色/字体/版式逻辑/密度/动效/质感）
        ↓
不给的是：具体哪一段用什么版式、字放哪、图放哪
        ↓
⇒ 所以每单仍然长得不一样，但"味道"是统一的
```

⇒ 这和"套模板"有本质区别：**模板锁死版式，风格库只给倾向**。

## 六、实施建议（分三步）

| 步 | 做什么 | 花费 |
|---|---|---|
| **1** | 把 1、2 两种风格接进日报线（素材卡加一个"视觉风格"下拉，默认"暖纸宋体"= 现状） | **1 天** |
| **2** | 把 3~6 种也接上 | 含在 1 里 |
| **3** | 记录"用了哪个风格 + 满意度"，让默认值自动优化 | **1.5 天** |

⇒ **第 1 步就能让你今晚选"瑞士网格"出一单试试**。

⇒ 全部默认关闭（不选 = 现在的行为，一个字不变）。
